# `Home-_-folio-assistant.pdf`

A print of the folio-assistant home page. It came in with the seven WHO
publications that `litlfred/qou` received in
[a3d2266](https://github.com/litlfred/qou/commit/a3d2266a1b08018af5f8f88c222c1e7b45e6a36c),
where it was named `Home _ folio-assistant.pdf`.

**It was never ingested, and that was deliberate.** Ingesting the platform's
own rendered docs as WHO subject matter would cross the platform/content
boundary. So the argument for removing the other seven from qou, *"the
source is safely ingested elsewhere"*, did not apply to this file. It needed a
separate ruling, and the owner gave one on 2026-10-03: **"Move it to
fsh-guts"**. This copy is the kept half of that move. Bean
`folio-assistant-fgkb` records the qou half.

**The bytes are identical to the qou file.** They were copied from this
repository's own `uploads/Home-_-folio-assistant.pdf`, which has the same
sha256. Bean `fgkb`'s 2026-09-22 pass recorded only the PREFIX of qou's
digest (`783058fd…`), and that prefix matches. The full digest has to be
compared against qou's file again before anything is removed there. A prefix
match is not a verification. The space-free name is the one this repository already used, so the qou
spelling is kept in `movedFrom` instead.
