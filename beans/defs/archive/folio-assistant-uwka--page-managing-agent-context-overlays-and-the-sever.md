Owner, 2026-09-21: a new page in the cat-harness docs explaining the concept of OVERLAYS.

It applies to contextual information that is generated in several different ways — agent directives, `memory.md`, and others. Overlaying a context is what lets testing run repeatably across different contexts, which is the Context subgraph's reason for existing.

Relates to `3q47` (deterministically set an agent's context from the KG at each Task) and to the Context subgraph in the Knowledge Graph page. Should not restate either.
