## Decision (owner, 2026-11-02 18:20Z, card Q-BM-1 = A)

Every document: front (title, summary/abstract, how to use) / numbered chapters / back = Annexes, Glossary, References. Acronyms is a SUBSECTION of Glossary: an acronym is a glossary term's SKOS `notation` (folio-glossary/v1), so it is a view of the glossary graph, not a separate graph. Opening a document must land on its title and summary, never on end matter.

## Rules learned

- Chapter order lives in each paper manifest `folio/<doc>/<doc>.ts` (`chapterRef` list). No front/back-matter field exists in the cat-harness-tools schema.
- Block files resolve from `folio/<doc>/<chapter-dir>/`, so nesting a section means `git mv` its block files into the glossary dir. KEEP every label (public comments, review sheets and contributor logs cite them).
- After moving blocks: update `review-anchors.json` (frozen ones by hand: dpi-h-ra; drafting ones regenerate with `bun run review:anchors`), any `front-matter/<block>` node paths in `l1-coverage.json`, and glossary-table `block` paths. Run `check:kg-blocks`, `check:review-anchors`, `check:l1-coverage`.
- Merging dpi-h-ra's two SKOS schemes (acronyms vs glossary) is CONTENT: smart-ra is paused for content. Do not.
