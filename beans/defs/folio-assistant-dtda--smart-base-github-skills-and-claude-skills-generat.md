## Why

Parent: `folio-assistant-95e7`. cat-harness-tools `scripts/install-skills.ts --host copilot|claude` already writes `<host dir>/<prefix>-<name>/SKILL.md` with `INSTALLED_MARKER` and has `--check` for drift (bean `cat-tools-0nxe`). Nothing stops a hand-written file appearing beside them, which is how `.github/skills/` became a code library.

Blocked on bean `folio-assistant-hhkw` (the hand-written files must be gone first).

## Done when

- [x] smart-base runs `install-skills --host copilot` and `--host claude`; `--check` runs in PR CI (`litlfred/smart-base#382`).
- [x] A gate (cat-harness-tools, so every layer gets it) fails when a file under a host skill directory lacks the installed marker (`unmarkedFiles` + `--check` in `scripts/install-skills.ts`, `litlfred/cat-harness-tools#2111`).
- [x] A gate fails when a workflow `run:` invokes a path under `.github/` other than `.github/workflows/` or a declared directory (`githubPathFindingsFrom` + `isAllowedGithubInvocation` in `scripts/check-workflow-paths.ts`, `litlfred/cat-harness-tools#2111`).
- [x] The `SGAuthoring.Skills.*` Requirements and `input/pagecontent/authoring-skills.md` link to the KG tool pages, not to `.github` paths (`litlfred/smart-base#376` + `litlfred/smart-base#386`).
