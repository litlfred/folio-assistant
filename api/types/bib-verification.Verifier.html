    Verifier:
        | { kind: "agent"; model: string }
        | { agent_assistance?: { model: string }; kind: "human"; name: string }

    Discriminated union: agent-only vs human-adjudicated verifier.

    The two cases convey different epistemic weight. kind: "agent" is a machine-generated claim awaiting human review; kind: "human" is a human adjudication, which may have been assisted by an agent but is the human's stated position.
