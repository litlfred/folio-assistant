      }

      What makes this mount trusted: a person's consent for THIS pin, or a signature in a declared trust network (schemas/kg/mount-trust.ts, bean ieum, rule H8). Absent means unsigned and unconsented, and a non-staging mount is then refused rather than fetched.

      • Optionalconsent?: {
        by: string;
        evidence: string;
        on: string;
        ref: string;
        standing?: { consentAt: string; follows: string; require?: "green" };
        }
        • by: string

          Who consented: a person, by the identity they act under here.

        • evidence: string

          Where the consent was given (an issue comment, a chat session), so it can be read.

        • on: string
        • ref: string

          The pin consented to. Must equal the mount's ref; a moved pin asks again.

        • Optionalstanding?: { consentAt: string; follows: string; require?: "green" }

          Present when this pin's consent was written under a STANDING consent (trust.standing), by the repin tool rather than by the person at this pin. It holds only while that rule is still declared, unchanged.

      • Optionalsignature?: { keyId: string; network: string; signedDigest: string; value: string }
        • keyId: string
        • network: string

          The trust network the key is listed in, e.g. gdhcn.

        • signedDigest: string

          What was signed: the pinned declaration's sha256, as the lock records it.

        • value: string
      • Optionalstanding?: {
        consentAt: string;
        consentBy: string;
        evidence?: string;
        follows: string;
        require?: "green";
        }

        A standing consent for this instance: see "Standing consent" above.

        • consentAt: string

          When it was given. Part of the rule's identity: a re-given rule re-asks every pin under the old one.

        • consentBy: string

          Who gave the standing consent — recorded as consent.by on every pin it covers.

        • Optionalevidence?: string

          Where it was given, so it can be read. Optional: consentBy and consentAt are the record.

        • follows: string

          The upstream branch whose newest commit the pin follows.

        • Optionalrequire?: "green"

          green: only a commit whose own combined status / checks are green. Absent: the branch head.
