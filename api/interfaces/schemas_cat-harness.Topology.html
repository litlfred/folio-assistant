    Interface Topology

    The topology axes an instance declares about ITSELF.

    The ten axes from deployment-topologies.md

    Ten axes model WHERE the instance and its artefacts live. Each field is optional, and absent means "has not said", never a default.

    publication.host is axis 3 and lives on Publication rather than here, because it answers a publication question and has two other fields it must be told apart from.

    interface Topology {
    compute?:

    | "vendor-cloud"
    | "jurisdiction-cloud"
    | "own-infrastructure";

    forge?: "none" | "github" | "self-hosted" | "jurisdiction-hosted";

    toolSurface?: "mcp" | "cli" | "both";
    visibility?: "public" | "private" | "internal";
    }
