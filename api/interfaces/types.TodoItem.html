    Interface TodoItem

    A todo item attached to a content block or section.

    Serves as the unit of agent-to-agent and human-to-agent communication. Each todo lives in the todos field of a block manifest (.ts) or in a standalone todos manifest for section/chapter-level items.

    The comment field is a quick markdown narrative. The optional data field carries structured context at the discretion of the creating agent or user.
