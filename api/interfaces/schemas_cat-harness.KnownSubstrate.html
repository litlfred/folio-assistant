    Interface KnownSubstrate

    A substrate this harness knows of that NO declaration in the checkout names. Issue #1719, owner: "cat-harness should list known substrates now and as part of separation plans."

    Hand-entered only where no fact already exists. Every staged instance already declares its planned repository (#1652), and every associated harness its repository, so the registry DERIVES those rows. Listing them again here would be a second copy of a fact, free to drift. This list is for the rest: a proposed substrate with no instance yet (the WHO World Health Data Hub), or a status only a person knows (a repository created today). scripts/subscriptions-viz.ts merges the two, and a hand row overrides a derived one by name.
