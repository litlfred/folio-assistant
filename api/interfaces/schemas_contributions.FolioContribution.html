    root?: string

    The contributing instance's root directory, absolute.

    Pinned by loadContributions from the dependency entry, for the same reason name is: a contributor that could name its own root could point the sweep at bytes it does not own. Absent when nothing the contributor supplies needs a file resolved — a contribution carrying qaCheckers without it is refused.
