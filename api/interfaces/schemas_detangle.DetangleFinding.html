    Interface DetangleFinding

    A finding this scanner raises, in the shape schemas/qa-review.ts defines.

    Deliberately NOT a bespoke verdict type. The review model already has a reviewer kind for a script, a machine severity axis, and a Decision by which an adjudicator may overrule — inventing a second vocabulary here would give this repository two answers to "what did the check say and what did we do about it", free to disagree.

    interface DetangleFinding {

    detail: string;
    id: string;
    metrics: DetangleMetrics;
    reviewer: { id: string; kind: "script" };
    severity: "major";
    subject: string;
    }
