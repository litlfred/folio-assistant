    Interface HarnessConfig

    The full harness.config.json shape.

    Not all fields are covered here — only the ones that have TypeScript consumers. The JSON file may carry additional fields (e.g. adapter, adapterModule, viewer, simulators) that are consumed by other parts of the system.

    Optionalcontributes

    contributes?: string

    Module this instance contributes from when it is loaded as a DEPENDENCY.

    Resolved relative to this folio's own root. Its default export is called with no arguments and returns a contribution object (or a promise of one). Read only for dependencies — a root folio's own contributes is ignored, because the root already is everything it would contribute.
