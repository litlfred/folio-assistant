      Whether an archival copy is obligatory, and why.

      Returns the REASON with the verdict, because "you must archive this" is an instruction somebody has to act on and an unexplained one gets ignored.

      The rule, in one sentence: a reference is a promise that the thing will still be there and still be the same thing, and a volatile source cannot keep it. A silently-changed citation is worse than a broken one — a broken link announces itself.

          The characterisation the "ingest a new data source" process produces. Required — these are what decide how the source may be REFERENCED, and a descriptor that has not said cannot answer that question.

          • availability: "unknown" | "blocked" | "reachable" | "offline"
          • basis: string

            How each of the above was established. A characterisation with no basis is an assumption.

          • hasOwnSearch: boolean

            Does the source offer a search a reader could be sent to instead?

          • large: boolean

            Is acquiring all of it a different activity from acquiring some? Judgement, not a byte threshold — what is large for a laptop is not large for a cluster, and the descriptor records the CALL with its basis rather than pretending a universal number exists.

          • remote: boolean

            Is it somewhere else? A local corpus raises none of these questions.

          • volatility: "unknown" | "versioned" | "revised" | "volatile"
        • enumeration: {
          basis: string;
          method: string;
          pageSize?: number;
          rateLimit?: number;
          totalNodes?: number;
          }
          • basis: string

            How the two numbers above were arrived at. A denominator with no provenance cannot be checked.

          • method: string

            How the whole is listed. Prose, because it is an instruction to a human or agent, not a URL template.

          • OptionalpageSize?: number
          • OptionalrateLimit?: number

            Requests per second the source tolerates, where it says. Absent means unstated, not unlimited.

          • OptionaltotalNodes?: number

            Total nodes, where the source publishes it. undefined is UNKNOWN and never zero.

        • id: string
        • identifiers: { authoritative: boolean; example?: string; name: string; note?: string }[]
        • nodeKind: string

          What one node IS in this corpus. Different per source, and never assumed.

        • OptionalsubsetBasis?: string

          Why subsetIsSelfContained has the value it has. Optional, because a self-contained source (IRIS: fetch an item and you have it) has little to say; the false case is the one that needs its reason recorded.

          Added 2026-09-23 (bean w5bn). mathlib carried this as an _subsetIsSelfContained_note key, which .strict() rejects, so the second worked descriptor, the one meant to prove the abstraction, had failed its own schema since it was written. Nothing noticed, because no gate read sources/. A field is checked; an underscore is not.

        • subsetIsSelfContained: boolean

          Whether a subset chosen by the strategies above stands on its own. false means every request must be closed over dependencies first.

        • subsetStrategies: ("container" | "identifier" | "facet" | "range" | "closure")[]
        • Optionalsystem?: string

          The software, where there is some — DSpace 7, Lean 4 / Lake. Descriptors for one system are often reusable.

        • OptionaltermsUrl?: string

          Whether the source states terms, and where. Feeds the restrictions and copyright gates; unknown stays unknown.
