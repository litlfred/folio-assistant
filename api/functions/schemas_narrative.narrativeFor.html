      The ONE narrative a single-text display shows from a slot: the entry in the reader's language, else the first. Owner ruling 2026-10-20 (bean cat-tools-e1lo, stage 3, "locale match, else first").

      Match order, so a regional locale still finds its language:

      1. an entry whose lang is exactly lang (case-insensitive, as BCP 47 is);
      2. an entry whose primary subtag matches (fr-CA finds fr, and fr finds fr-CA);
      3. the first entry.

      The empty slot has no choice to make and is returned as it is. A build with no locale passes none and gets the first entry.
