      The module name an entry provides — imports when given, else the distribution.

      Parameters

      • d: {
            distribution: string;
            imports?: string;
            tier: "lean" | "extended";

        }
        • distribution: string

          The distribution name pip installs, e.g. pdfminer.six.

        • Optionalimports?: string

          The module name Python imports, when it differs from the distribution.

          PyYAML imports as yaml, pdfminer.six as pdfminer, camelot-py as camelot. Without this mapping a checker comparing imports to declarations reports three false gaps, which is how such a checker gets switched off.

        • tier: "lean" | "extended"
        • Optionaltransitive?: boolean

          Nothing imports it directly; it is required by something that does.

          Pillow is the case: pypdf refuses image extraction without it and raises at the point of use, so it is a real requirement that no import statement will ever reveal. Stated, so "declared and unimported" is distinguishable from dead weight — which is what the checker would otherwise have to guess.

        • why: string

          Why this is declared — and for a transitive entry, why it has no import of its own.

      Returns string
