      The status of one block, from its record and its text NOW.

      body is proseBody of the block's text file, or null when that file could not be read — unreadable, never not-summarised, because a block with no readable text cannot be summarised and must not sit in a backlog nobody can drain. An empty body is empty for the same reason.
