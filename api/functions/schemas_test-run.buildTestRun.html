      Assemble a run. Pure apart from reading the files it hashes.

      Refuses a run whose bases overlap — see the module note. The refusal is at construction rather than in a later check because a recorded run with dependent hashes is indistinguishable, afterwards, from one with independent ones.

        WHAT was tested.

        • hash: string

          12-char SHA-256 prefix over the inputs in listed order, or unknown.

        • inputs: string[]

          Repo-relative paths, sorted. Never empty: a hash over nothing is not a hash.

      • outcome: Record<string, unknown>

        The measurements themselves, in whatever shape the runner records.

      • process: { hash: string; inputs: string[] }

        WHAT TESTED IT — runner, configuration, scenario bank.

        • hash: string

          12-char SHA-256 prefix over the inputs in listed order, or unknown.

        • inputs: string[]

          Repo-relative paths, sorted. Never empty: a hash over nothing is not a hash.

      • subject: string

        What this run measured, for a reader who has only the file.

      • updated_at: string

        ISO-8601 UTC. Deliberately NOT part of either hash: when a run happened is not what makes it reproducible, and including it would make every run differ from every other by construction.
