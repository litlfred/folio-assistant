    Function parseReference

    • parseReference(
      ref: string,
      contributedPrefixes?: readonly string[],
      ): ParsedReference

      Parse one uses[] / foreshadows[] / proofs[] entry.

      The grammar, per schemas/types.ts and constraints.ts:citesProvable, admits an arbitrary namespace path before the kind prefix:

        def:quantum-universe                          same paper
        unital-groebner-bases:cor:pbw                 cross-paper
        some-ns:unital-groebner-bases:cor:pbw         nested namespace
        https://folio.example.org/papers/foo#def:bar  cross-folio

      The kind prefix is the pivot: everything before it is namespace, everything from it onward is the local label. A slug may itself contain colons (def:foo:bar), which is why the first kind prefix wins rather than the last colon losing.

      Parameters

      • ref: string
      • contributedPrefixes: readonly string[] = []

      Returns ParsedReference
