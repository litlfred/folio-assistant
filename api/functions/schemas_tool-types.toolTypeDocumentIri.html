      The per-type document's IRI, <base>/tool-types/<Name>.schema.json: the $id each published per-type schema carries (bean tdir).

      Two phases, so no layer is ever broken by another's main. A port's schema still uses toolTypeIri's fragment form, because the tools layer's main reads that form; this PR adds the per-type documents and toolTypeNameOf, which reads both. Once the tools layer reads ports through toolTypeNameOf, toolTypeIri returns this IRI and the fragment form retires.
