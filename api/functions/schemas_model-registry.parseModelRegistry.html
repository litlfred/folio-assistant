      Parse a registry, or say why it cannot be parsed.

      Throws rather than returning a default. A registry this code could not read is not a registry with no models: reporting it as empty would make "nobody has declared a model" and "the file is malformed" the same answer, and an agent would then fall through to English believing a determination had been made.
