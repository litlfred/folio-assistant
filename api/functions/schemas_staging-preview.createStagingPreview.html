      Create the record, at deploy time.

      movedFrom carries the preview's URL when the host is known. The base schema calls that field "the field that earns the schema" — without it a trashcan node is an orphan, a reader seeing what it says and not where it came from. For a preview, where it came from is where it was served.

            pr?: number;
            slug: string;
        }
        • branch: string

          Branch the preview was built from.

        • builtAt: string

          ISO-8601. When the preview was built.

        • commit: string

          Head commit at build time.

        • Optionalhost?: string

          WHICH HOST rendered it — never assumed to be gh-pages.

          Bean 1lfx is this field's own bean: a staging deployment must report where it landed rather than letting a reader infer it from a convention that holds today. Optional here because a deploy that cannot determine its host must say nothing rather than guess, per the three-state rule.

        • Optionalissue?: number

          Issue the pull request is for, where it names one.

        • Optionalpr?: number

          Pull request number, where the deploy was triggered by one.

        • slug: string

          The STAGING/<slug> path segment. Derived, never reversed.
