      The prose a decision is presented as — the comparison BEFORE the question.

      This is the half that gets skipped, so it is the half that is generated. The recommended option is first and marked, per §4.2, and the table is a real table so the rows can be read against each other — which is the whole of why decision-comparison refuses a comparison written into a selection tool's labels.

        • Optional$schema?: "folio-decision/v1"

          Tag identifying the file's contract, when one is written down.

        • because: string

          Why that one, in the author's own reasoning.

        • decides: string

          What is being decided, as what will DIFFER depending on the answer.

          Not the NAME of the decision. §4.1 part 1 is explicit, and the worked failure there is a turn that said "I'd want your call on prefix-at-rest vs prefix-at-install" — a name, twice, and nothing that differs.

        • glossary: Record<string, string>

          Every identifier expanded: bean ids, paths, names coined elsewhere.

          Required, and {} is a legitimate value meaning nothing here needs a gloss. Optional would let it be forgotten, and §4.1 says the names most likely to reach the reader undefined are the ones the author coined an hour ago — "precisely because you can no longer see them as new".

        • ifSilent: string

          What the author will do if the reader says nothing. Then they do that.

        • options: {
              con: string;
              does: string;
              downstream: string;
              label: string;
              pro: string;
              reversibility: string;
          }[]

          Two to four options, each fully compared.

        • othersPending: number

          How many OTHER decisions are waiting.

          §4.1's count rule: with several open, ask one in full and give a COUNT for the rest — never a list of option names without their costs, which "invites exactly that, which is why the compact list is worse than silence". Required so the author states it rather than omitting it.

        • question: string

          The question itself, last.

        • recommends: string

          The label of the recommended option. Checked to be one of them.
