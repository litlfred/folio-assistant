      May this actor do this, here? Evaluated against one policy and everything it inherits.

      • A matching prohibition and no matching permission: deny.
      • A matching permission and no prohibition: permit, unless the request names a cat-harness:role the actor is not eligible for. Performing a task in a lane needs both the permission and the role, as role-model.md keeps them apart.
      • Both: the policy's conflict decides (the folio default is odrl:prohibit); odrl:invalid voids the policy, which is deny.
      • Neither: unknown.
