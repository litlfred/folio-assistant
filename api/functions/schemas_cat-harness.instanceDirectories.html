    Function instanceDirectories

    • instanceDirectories(
      root: string,
      decl?: CatHarnessDeclaration | undefined,
      registry?: GraphTypologyRegistry,
      ): (ContentDirectory & { within?: string })[]

      An instance's OWN sub-graphs: its declaration's entries as authored, then the ones it declares FROM WITHIN them (bean cmsl: skills/skills.json declaring voices/), with paths relative to the instance root.

      For a consumer that enumerates "the sub-graphs this instance has" — one diagram, one page, one visualiser per entry. Reading decl.directories alone silently drops every entry that moved inward: measured 2026-09-30, the UML overview deleted five voices diagrams and check:wireframes reported five voices pages as undeclared, with nothing else red.

      Unlike nestedDirectories this also reaches a nested declaration under a DEFAULT parent (agent-skills never declares skills/), and it returns only entries that answer dependents — the instance directories, not the parts of one graph (voices.json's vendors).
