      Check every tag against the graph, reporting three states per tag.

      Reports rather than throws, for the reason kg-export reports its dangling declaresSkill edges rather than failing: a todo naming a role somebody later renamed is a data defect in content a person wrote, and blocking on it would hold the folio hostage to a backlog.

          Issues, pull requests, commits. See ArtefactRefSchema.

          Separate from references because these do not resolve against the knowledge graph at all — a resolver that tried would report every one of them dangling, which is worse than not checking.

        • identities: { actor?: string; displayName?: string; id: string; provider: string }[]

          An array because several people can be tagged on one note — a question for two reviewers is one item, not two, and splitting it would lose that they are being asked the same thing.
