      This instance's declared assets, resolved to absolute paths.

      Existence is reported rather than filtered, unlike the directory defaults: a declared asset that is missing is a FINDING — somebody said this file is ours and it is not there — whereas a conventional directory that is absent is simply a convention this instance did not take up. Silently dropping the first would reproduce dh4f in the one place the declaration is an assertion rather than a guess.
