    The composed schema: carried note, then themed, then the todo's own fields.

    theme arrives from the themed parent rather than a spread. It was a spread until bean a1lq, and a spread is last-writer-wins with no record that two parents were composed at all. The parents are now declared, and the composition is the one walk instances use.

    theme — the id of the theme this todo's sticky renders with — was declared by ThemedTodoFieldsSchema all along and merged in by nothing, so it was authorable in principle and dropped in practice (bean 5y4b). Absent means nobody has chosen: the todo takes the graph's defaultTheme, else a flat card.
