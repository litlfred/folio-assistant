    The steps and check scripts a repository's CI runs that the local gate set does not, each with its reason — read by the tools layer's gates.ts (beans 0r7u, ot9a).

    Declared by whoever OWNS what is exempted: a layer for its own scripts and steps (gateExemptions on its declaration), and an index for the steps of its own workflows (gateExemptions in index.config.json). An index declares no layer, so before this its workflow steps were exempted from a layer's declaration instead, AHEAD of the workflow change — and a layer re-pinned before the workflow landed carried an exemption that matched nothing CI ran (qa:publish --add, 2026-10-14).
