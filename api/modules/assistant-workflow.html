    Module assistant-workflow

    Assistant Workflow — Content lifecycle state machine.

    Defines the general content development lifecycle that applies across repositories (qou math authoring, WHO SMART guidelines, etc.). Each skill package realizes this lifecycle with domain-specific skill assignments.
