    Module schemas/skill-topics

    The shape of skills.json, the labelling node that says which subdirectories of a skills directory are TOPICS (bean 9umr).

    Graph Node

    schema

    Its own module, depending on zod alone, because scripts/skill-topics.ts parses with it and that is imported by scripts/known-skills.ts — a schema file that pulled in cat-harness.ts would make the skill walk import the whole declaration reader. Registered as the skill-topics/v1 family of the skills graph typology, so check:kind-validators grades the committed file against the same schema the reader parses with.
