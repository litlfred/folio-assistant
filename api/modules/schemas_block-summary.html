    Module schemas/block-summary

    An agent's summary of a library block, kept BESIDE the block — the QA sidecar the owner asked for on 2026-09-24.

    on library/ page, the extract of a node is shown, but no agentic summary

    and, on scope:

    Make as QA sidecar as part of general doc ingestion to slowly drain.

    Why a sidecar, and not a field on the block

    A prose block is the source's own text: provenance: "ingested", extracted verbatim, regenerated by re-ingestion and never re-authored in place (library is holds: "derived"). A summary is somebody's account of that text. Writing it into the block would make the block carry an authored claim under an "ingested" stamp, and it would be dropped the next time the rung ran. So the block stays verbatim and the summary lives in library/<slug>/summaries.json, one file per entry — the same placement images.json uses for image descriptions, and for the same reason.

    One vocabulary for the state and the author

    Each summary IS a NarrativeSchema: draft, confirmed, rejected, with drafted_by an AttributionSchema that must name its model when the author is an agent, and confirmed_by that must be a human. Nothing here restates those rules, so nothing here can drift from them. bun run narratives reviews these drafts exactly as it reviews image descriptions.

    source_hash — so a changed source reads as STALE, not as right

    The kg-qa sidecars (schemas/kg-qa.ts) record the hash of the subject they judged, because a verdict that outlives its subject silently describes something else. A summary has the same failure: re-ingest a document, a section's text changes, and the old summary goes on sitting beside the new text looking current. The hash is of proseBody — the text the summariser was actually shown — so a change to the section's front matter alone does not mark a summary stale, and a change to one word does.

    Absence is the "not yet summarised" state

    A record whose narrative is not-authored is refused. An empty slot would be a second spelling of "no record", and two spellings of one fact is how a count comes to disagree with itself.
