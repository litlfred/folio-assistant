    Module schemas/namespaces

    The platform's own IRI namespaces.

    Not in schemas/kg/jsonld.ts

    jsonld.ts is the content vocabulary (block kinds, DoCO, SPAR, FHIR and WHO SMART Base namespaces) and imports ./block-kinds. schemas/kg/cat-harness.ts — the root declaration every layer carries, including a Tool or Test repo with no content — also needs the platform namespace to mint the @type IRIs for its graph kinds. Importing it from jsonld.ts would make the harness depend on the content model, a wrong-direction edge bun run cat check:partition reports. So this module is the one definition, it partitions to the harness (core may import the harness, not the reverse), and jsonld.ts re-exports it.

    none — a single IRI constant, not a schema
