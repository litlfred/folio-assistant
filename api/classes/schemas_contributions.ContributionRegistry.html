    Class ContributionRegistry

    Accumulates contributions as the dependency tree is walked.

    Deliberately an instance rather than module-level state: tests, and a root that resolves more than one folio in a process, must not leak registrations into each other. Module-level mutable state is also how load order becomes un-debuggable, which this shape is already paying enough for.
