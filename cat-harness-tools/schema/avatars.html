Description

An avatar for every declared kind — in and out of the trash, in both schemes.

The glyph is a MASK, not an image or an inline <svg>

Each avatar is one path, served through mask-image, so the colour comes from background-color and a scheme swap is a CSS custom property, not a second set of assets. docs-ui.js sets data-fa-kind and the stylesheet does the rest, so it works with no script.

The trash state is DERIVED

An item in the trash is the same glyph, muted, under the crumple overlay that marks a discard — never a second drawing that could drift. So trash coverage is automatic: the QA axis checks only that every kind has a glyph, and asserts the derivation exists.

kind is open, so there is a fallback and it is reported

BASE_GRAPH_TYPOLOGIES is an open registry and fsh-guts node kinds are open by design. An unknown kind gets GENERIC and shows up as a QA finding — never as a blank.
