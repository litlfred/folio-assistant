Description

The filter a READER applies to a board, which commits nothing.

Two filters

A board's DECLARED filter — module:schemas/board's pages and kinds — says what the board IS. A reader's filter narrows their own view at view time. Conflating them would let one reader's view edit the board everyone opens, so this module holds no $schema tag, no file name, no reader and no writer: like window-stack.ts, it is state, not a document.

The reader's filter can only NARROW

Composition is boardContent first, then this, so a reader never sees something the board does not show. visibleOn enforces the order, and reader-filter.test.ts asserts the subset property over generated cases.

Same logic as the declared filter

OR within an axis, AND across them. An axis that is ABSENT does not filter. An axis present but EMPTY is refused by readerFilterProblem rather than treated as "match nothing".
