Description

WHERE BYTES CAME FROM — the source-side provenance pair, and a signature.

Not to be confused with ProvenanceSchema in cat-harness/schemas/content/attribution.ts (INGESTED | Attribution), which answers who wrote this; SourceProvenance answers where these bytes came from. It lives in the harness so both the harness's intake record and the content core can use it.
