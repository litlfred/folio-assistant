# smart-immunizations

The artefact index of the **WHO SMART Immunizations** Implementation Guide,
rebuilt from what the IG publishes.

| | |
|---|---|
| Package | `smart.who.int.immunizations` v0.2.0 |
| FHIR | 4.0.1 |
| Published at | <https://worldhealthorganization.github.io/smart-immunizations> |
| Artefacts | 748 — 548 referenced, 200 materialized |
| DAK API | present — 198 schemas, 198 OpenAPI, 188 displays, 190 JSON-LD |

`fhir-artifact-index/index.json` lists every artefact with its canonical URL,
published representations, and DAK API sidecars. The index is **reconstructed**,
not downloaded: no FHIR IG publishes an artefact-index document, so each field
records in `provenance` which published file it came from.

This instance is **provisional** — see [`AGENTS.md`](AGENTS.md) and bean `nsbb`.
It renders no pages by design.
