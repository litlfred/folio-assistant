served when it was fetched on 2026-10-08 (sha256 `9861c483644986f477485fdf98f61f493a4f1e2ace8e20f48c04ba70e0d18f8d`;

The 2024 edition was searched for on 2026-10-23 and not found:

- **who.int** replaced the 2024 file in place. Its December 2024 file name,
  `immunization_schedules/table_1_dec_2024_english.pdf` under
  `www.who.int/docs/default-source/immunization/`, now redirects to this
  December 2025 PDF (the same Sitefinity document id, a later version). The
  older `/immunization/tables/` files on cdn.who.int are earlier editions
  (September 2020; Table 4 March 2023), not 2024.
- **The Internet Archive** (web.archive.org) and third-party copies could not
