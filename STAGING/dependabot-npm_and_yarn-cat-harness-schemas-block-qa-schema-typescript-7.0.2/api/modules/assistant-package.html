    Module assistant-package

    Package Manifest — Docker and system dependency declarations.

    Each skill package declares its runtime requirements so the Docker image builder can aggregate dependencies across all active packages.

    Standards used

    Concern Standard
    Image metadata OCI Image Annotations
    APT versions Debian control file relationships
    Python versions PEP 440
    Node versions semver
    Health checks OCI image config

    Usage

    Each skill package exports a PackageManifest in its directory. The Docker image build aggregates all manifests from active packages (as declared in skills-config.json) to generate a unified Dockerfile layer.
