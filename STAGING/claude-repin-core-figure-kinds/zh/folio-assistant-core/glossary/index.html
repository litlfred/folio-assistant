人工编写的术语

Bootstrap terms

术语替代标签定义
节点—由 IRI 命名的一个文件，或可通过 IRI 片段寻址的文件的一部分。
引用—一个节点通过 IRI 对另一个节点的指称。
节点模式—可用来校验节点的模式：JSON Schema，或已发布的外部模式，例如 BPMN 的模式。
节点类型—与一个节点模式配对的名称。
子类型—一种节点类型，其节点模式要求另一节点类型的全部要求，因此满足它的每个节点也满足另一类型。
节点实例—在 $schema 或前置元数据中指明其节点类型，并满足该类型节点模式的节点。
图类型—一组具名的节点类型。
声明—一个 JSON 文档 <name>.json，给出名称并列出目录条目和文件条目。
扩展—声明或其某条条目中未在此处定义的字段。不识别该字段的读取方会忽略它，声明的其余部分保持原意。
子图—声明中的一条目录条目：一个 id、一个目录，以及其节点实例的类型所属的图类型。
资产—声明中的一条文件条目：关于仓库本身的一个文件，其 role 字段说明它的用途。
知识图谱—一份声明所列出的节点模式、节点实例和资产，对应仓库的某一版本。以 JSON-LD 发布时，每个子图的节点实例中的陈述构成一个具名图。
依赖—声明中的一条 needs 条目，用于指明另一个知识图谱。引用可以从本图谱的节点实例指向所指明的图谱，绝不反向。
内容—描述知识图谱主题内容的节点实例，例如记录、文档、目录及其术语，而不是如何使用该图谱。
任务—一个工作单元，以其开始所需和产出来描述。
行动者—能够执行任务的人、智能体或程序。
技能—A Node Instance stating a responsibility an Actor carries out to complete a Task: as natural-language instructions to follow, as a contract to be tested against, or both. (未翻译)
角色—命名行动者为执行任务所担任的职责，并列出该职责所需技能的节点实例。
流程节点—BPMN 流节点：一个活动（任务或调用活动）、一个网关或一个事件。
顺序流—BPMN 流程中从一个流程节点到下一个流程节点的有向连接。
流程—包含协调任务的 BPMN 流程的节点实例：其流程节点由顺序流连接，位于各自指明一个角色的泳道中。
工具框架—其子图包含技能、角色或流程的知识图谱：行动者用来处理知识图谱（包括其自身）的工具。

Folio Assistant platform terms (cat-harness)

术语替代标签定义
关联框架—本框架按名称、站点和仓库知晓、但从不加载、构建或复制的另一个框架。这是依赖（needs）、引用（remoteGraphs）和使用（dependencies）之外的第四种关系。
策略—哪个行动者可以在何处执行哪项操作，以按流程、任务和角色限定范围的 W3C ODRL 2.2 许可与禁止规则表述。
许可—一条 ODRL 规则，允许某一受让方执行某一操作，可选地限定目标并附带约束。对较宽泛操作的许可，同时许可其中包含的所有操作。
任务执行—行动者以某一角色、在某一策略下对 BPMN 任务的一次执行，记录为以该任务为计划的 W3C PROV-O 活动。
行动者—一个具体的参与者，可以是人、智能体或机械程序，贯穿所有流程并担任角色。哪个登录名对应哪个行动者，由数据存储负责掌握。
角色—泳道：行动者因其所在泳道而担任的角色形象，承载该泳道中各活动所需的技能。
user story (未翻译)—What a reader acting in a Role is trying to do, told as that role: as a , I want , so that . The story points at its role; the role names no story. _(未翻译)_
test run (未翻译)—One measurement of a Skill: which skill it tests, the cases it exercised, and a hash of the data and a hash of the process that produced the result, so a third party can redo it. Its cases are checked against the skill’s input and output contracts. (未翻译)
voice (未翻译)—A named set of writing rules for prose, active in the roles and processes it names. The voice points at the role it is written for; the role names no voice. (未翻译)
external schema (未翻译)—A record of a specification the platform depends on but does not hold: which authority publishes it, which version is conformed to, and the operative terms used from it. (未翻译)
KG QA report (未翻译)—A committed QA sidecar recording, for one knowledge-graph subject such as a process, role or skill, which of its references fail to resolve under each audit criterion. (未翻译)
todo (未翻译)—One person’s outstanding work, as a content node the folio owns, tagged with the roles, processes and tasks it concerns. Not the agent work plan, which is beans. (未翻译)
bean (未翻译)—One item of the agent work plan, held by the beans CLI in the committed beans/ store, with a status, a parent and the beans it blocks. (未翻译)
JSON Schema (未翻译)—A JSON document that describes the shape of other JSON documents. In the platform, a node schema and a skill’s input and output contracts are each a JSON Schema file. (未翻译)

public health (未翻译)public health guideline (未翻译)A guideline whose recommendations address the health of populations rather than of an individual patient: prevention, health promotion, immunization and screening programmes, surveillance, and policy or environmental measures. (未翻译)
health system strengthening (未翻译)health systems strengthening (未翻译); HSS (未翻译)A guideline whose recommendations address how the health system itself is organised and resourced — service delivery, health workforce, health information systems, access to medical products, financing, and leadership and governance — rather than a particular condition or population intervention. (未翻译)
