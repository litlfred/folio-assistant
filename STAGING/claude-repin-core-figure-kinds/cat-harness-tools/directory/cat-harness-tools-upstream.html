descriptionThis layer's pinned-upstream registry, `upstream-pins.json` (`"$schema": "folio-upstream-pins/v1"`). It has one row for each upstream dependency whose pin literal is in a file this layer holds. Today that is only the pdf.js viewer, pinned in `scripts/pdf-viewer.ts`. Each row names the file the pin is READ from (`pinnedIn`, resolved against this instance's root), the pattern that reads it, and what of ours binds to the dependency. It holds no version. `bun run cat check:upstream-pins` reads it together with cat-harness's `upstream/` registry (`cat-harness-upstream`), which keeps the rows whose files are in the harness. It is a separate registry because a harness row naming a file in this layer is a wrong-direction reference (folio-assistant#1481). `code`: the checker's input table, not content any reader renders.
