Candidate terms extracted from every Tool node: title as the label, description as the definition, the Tool id as the code. Each is the asset’s own text, verbatim and not curated, and carries the badge “candidate, extracted”. A person promotes one by authoring it. Authored terms, the counts and the sources are on the glossary index.
