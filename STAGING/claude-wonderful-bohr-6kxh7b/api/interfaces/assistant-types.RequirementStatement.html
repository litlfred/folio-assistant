    Interface RequirementStatement

    A single testable statement within a requirement.

    Each statement has a conformance verb (SHALL/SHOULD/MAY) and optional satisfiedBy references that trace to skills, capabilities, or other requirement statements.

    Example

    {
      key: "REQ-SS-1",
      label: "Identity detection",
      conformance: "SHALL",
      requirement: "Detect user identity via git config or OAuth",
      satisfiedBy: [{ kind: "capability", ref: "git-read" }],
    }
