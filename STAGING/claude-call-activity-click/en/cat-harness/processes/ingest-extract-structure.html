Extract the text layer
Task_ExtractText		Ingestion Engine (agent, runs unattended)document-intakeThe document has a text layer: extract it with pdf-extract (pdfminer.six, then a zero-dependency content-stream reader). Exit 2 means no text layer — a scan — and routes to OCR; it is not an empty document.
OCR to ocr/page-*.txt
Task_Ocr		Ingestion Engine (agent, runs unattended)document-intakeA document ingested this way keeps its text in ocr/ and only a stub in sections/, which the documented sections/ grep cannot see. That asymmetry is why the corpus-grep checklist has a fourth tier. The run also records WHICH SOFTWARE made the pages, in ocr/run-context.json: a folio-run-context/v1 (cat-harness schemas/run-context.ts, the record test runs and QA reports use for the same question), naming the OCR engine, the rasteriser and each language model with its version and the sha256 of the bytes that ran. Two OCRs of one scan can read differently (“Manual” and “Manval”, bean turh), and without it neither could be told from the other or reproduced.
Split into sections/*.md with doc_brief front-matter
Task_Sections		Ingestion Engine (agent, runs unattended)document-intakeContextual retrieval: a chunk in isolation loses what makes it mean anything, so each section carries the document brief.
Write structure.json (TOC, page ranges, metadata)
Task_Structure		Ingestion Engine (agent, runs unattended)document-intakeWrite structure.json (pdf-structure/v1): doc id, TOC from the PDF outline or inferred from headings, page ranges, metadata, and source{} with the sha256 and a mimetype sniffed from the bytes, never the extension. A structure that could not be determined says so in structure_note rather than being rendered as one. For OCR’d text, source.runContext cites the OCR step’s run context by sha256. A title already known for the document (the catalogue’s dc.title, or one given with –title) is passed through as the raw title, so the sections’ doc_title does not carry a scan’s misreading (bean turh).
Extract claim candidates
Task_Candidates		Ingestion Engine (agent, runs unattended)document-intakecandidates.json holds extracted theorems and definitions. Proposals only – never adjudicated verdicts.
