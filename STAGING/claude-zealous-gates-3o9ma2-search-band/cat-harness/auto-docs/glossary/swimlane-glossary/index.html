Adjudicator
glossary-ledger.json		Settles a criterion whose reviewer entries disagree, and records WHY. Inherits reviewer because an adjudicator is a reviewer with one added entitlement — the adjudication permission — and the separation is the point: a reviewer reports, an adjudicator settles, and a process where every reviewer could settle has no way to say who decided. The KNOWLEDGE spreads (several roles carry the adjudication skill, because each has to tell an adjudicable disagreement from a complaint); the ENTITLEMENT does not, and lives on the actor as a permission.

Merge steward
glossary-ledger.json		Stewards writes to ONE watched ref -- a long-lived branch several processes write and something downstream consumes serially. The ref is a parameter of the LANE INSTANCE, not of this persona, so main, gh-pages and each cat/cat-harness/* store branch can each have a steward without a schema change; scripts/special-branches.json is the declaration of which refs qualify. On main that work is a merge train: composes it from the queue, attributes and ejects on red, lands at the tested SHA. On a route-keyed ref it is coalescing: batches the writes arriving in one window into a single write. Decides nothing the reprioritisation table or the owner has not -- placement is computed by merge-priority.dmn, and landing waits for the owner's release. Records decisions on queue entries and windows, never the host's facts.
