nameContributor feedback on a working draft
summaryA document is still being written, and the Authoring Committee gives feedback on it in a shared Contributor Feedback sheet.
descriptionA document is still being written, and the Authoring Committee gives feedback on it in a shared Contributor Feedback sheet. This is what happens to ONE change set, one row of that sheet: a member starts it with a title, the sections it is about and their feedback; the agent proposes a direction; an Editor lets the agent edit; the agent makes the edit in the row's one pull request, whose staging preview shows what changed; the committee answers on the row; and an Editor lets the agent merge. If the row's feedback changes after the agent wrote its proposal, the proposal is marked stale and the row's Ready for agent goes back to No, so the agent proposes again and an Editor decides again. The sheet's colours follow the lanes: Blue for the committee, Green for the agent, Orange for the Editor. Skill: review-sheet-script.
