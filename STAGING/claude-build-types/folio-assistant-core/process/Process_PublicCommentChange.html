nameMake a decided public comment change
summaryCalled by Process_PublicComment (CallActivity_MakeChange) once the editor's decision on a comment changes the document.
descriptionCalled by Process_PublicComment (CallActivity_MakeChange) once the editor's decision on a comment changes the document. An author makes the edit on a feature branch, the change set is reviewed on its staging preview as any content change (Process_ContentChangeReview), an independent QA gate checks the dispositions against the pull request, and each comment the change set answers is marked incorporated when it merges. Drawn on its own page so that each phase fits the screen. Skill: public-comment.
