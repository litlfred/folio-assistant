nameRelease a draft for public comment
summaryThe whole public comment cycle around the comments themselves.
descriptionThe whole public comment cycle around the comments themselves. The committee and editor agree a release date; the draft is frozen as a public comment release with fixed line numbers (a PDF and a permanent PC/<version> site); the editor sets up every channel against that release, with instructions and links, and writes the announcement; the public is told; comments come back and are handled one by one in Process_PublicComment; and the release is archived with the review. Called from Process_Publication. Skills: public-comment, document-publishing.
enforcementstrict
