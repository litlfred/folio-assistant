Bootstrap terms

The terms Bootstrap defines, in order: each is defined only by terms above it, and never itself. Read from the schema that defines them, bootstrap/schemas/graph.schema.json, so this glossary cannot say anything that schema does not. SKOS.

1. Node

One file, or one part of a file addressable by an IRI fragment, named by an IRI.

Bootstrap terms · https://litlfred.github.io/bootstrap/0.1.0/ns#Node · defined by www.w3.org/TR/json-ld11/#node-objects · source bootstrap/schemas/graph.schema.json#/$defs/Node

2. Reference

A Node's naming of another Node by its IRI.

Uses: Node

Bootstrap terms · https://litlfred.github.io/bootstrap/0.1.0/ns#Reference · defined by www.rfc-editor.org/rfc/rfc3987 · source bootstrap/schemas/graph.schema.json#/$defs/Reference

3. Node Schema

A schema a Node can be checked against: a JSON Schema, or a published external schema such as BPMN's.

Uses: Node

Bootstrap terms · https://litlfred.github.io/bootstrap/0.1.0/ns#NodeSchema · defined by json-schema.org/draft-07/schema# · source bootstrap/schemas/graph.schema.json#/$defs/NodeSchema

4. Node Kind

A name paired with a Node Schema.

Uses: Node Schema

Bootstrap terms · https://litlfred.github.io/bootstrap/0.1.0/ns#NodeKind · defined by litlfred.github.io/bootstrap/0.1.0/schemas/graph.schema.json#/properties/nodeSchemas · source bootstrap/schemas/graph.schema.json#/$defs/NodeKind

5. Subkind

A Node Kind whose Node Schema requires everything another Node Kind's does, so every Node that satisfies it satisfies the other too.

Uses: Node Kind, Node Schema, Node

Bootstrap terms · https://litlfred.github.io/bootstrap/0.1.0/ns#Subkind · defined by litlfred.github.io/bootstrap/0.1.0/schemas/graph.schema.json#/$defs/Subkind · source bootstrap/schemas/graph.schema.json#/$defs/Subkind

6. Node Instance

A Node that names its Node Kind, in $schema or front matter, and satisfies that kind's Node Schema.

Uses: Node, Node Kind, Node Schema

Bootstrap terms · https://litlfred.github.io/bootstrap/0.1.0/ns#NodeInstance · defined by litlfred.github.io/bootstrap/0.1.0/schemas/graph.schema.json#/$defs/NodeInstance · source bootstrap/schemas/graph.schema.json#/$defs/NodeInstance

7. Graph Typology

A named set of Node Kinds.

Uses: Node Kind

Bootstrap terms · https://litlfred.github.io/bootstrap/0.1.0/ns#GraphTypology · defined by litlfred.github.io/bootstrap/0.1.0/schemas/graph.schema.json#/$defs/GraphTypology · source bootstrap/schemas/graph.schema.json#/$defs/GraphTypology

8. Declaration

A JSON document, <name>.json, that gives a name and lists directory entries and file entries.

Bootstrap terms · https://litlfred.github.io/bootstrap/0.1.0/ns#Declaration · defined by litlfred.github.io/bootstrap/0.1.0/schemas/graph.schema.json · source bootstrap/schemas/graph.schema.json#/$defs/Declaration

9. Extension

A field of a Declaration, or of one of its entries, that is not defined here. A reader that does not recognise the field ignores it, and the rest of the Declaration keeps its meaning.

Uses: Declaration

Bootstrap terms · https://litlfred.github.io/bootstrap/0.1.0/ns#Extension · defined by litlfred.github.io/bootstrap/0.1.0/schemas/graph.schema.json#/$defs/Extension · source bootstrap/schemas/graph.schema.json#/$defs/Extension

10. Subgraph

A directory entry of a Declaration: an id, a directory, and the Graph Typologies its Node Instances' kinds belong to.

Uses: Declaration, Graph Typology, Node Instance

Bootstrap terms · https://litlfred.github.io/bootstrap/0.1.0/ns#Subgraph · defined by litlfred.github.io/bootstrap/0.1.0/schemas/graph.schema.json#/$defs/Subgraph · source bootstrap/schemas/graph.schema.json#/$defs/Subgraph

11. Asset

A file entry of a Declaration: one file about the repository itself, whose role field says what it is for.

Uses: Declaration

Bootstrap terms · https://litlfred.github.io/bootstrap/0.1.0/ns#Asset · defined by litlfred.github.io/bootstrap/0.1.0/schemas/graph.schema.json#/$defs/Asset · source bootstrap/schemas/graph.schema.json#/$defs/Asset

12. Knowledge Graph

The Node Schemas, Node Instances and Assets one Declaration lists, as of one version of the repository. Published as JSON-LD, the statements of each Subgraph's Node Instances form one named graph.

Uses: Node Schema, Node Instance, Asset, Declaration, Subgraph

Bootstrap terms · https://litlfred.github.io/bootstrap/0.1.0/ns#KnowledgeGraph · defined by litlfred.github.io/bootstrap/0.1.0/schemas/graph.schema.json · source bootstrap/schemas/graph.schema.json#/$defs/KnowledgeGraph

13. Dependency

A Declaration's needs entry naming another Knowledge Graph. References may point from this graph's Node Instances into the named one, never back.

Uses: Declaration, Knowledge Graph, Reference, Node Instance

Bootstrap terms · https://litlfred.github.io/bootstrap/0.1.0/ns#Dependency · defined by litlfred.github.io/bootstrap/0.1.0/schemas/graph.schema.json#/$defs/Dependency · source bootstrap/schemas/graph.schema.json#/$defs/Dependency

14. Content

Node Instances that describe the subject matter of a Knowledge Graph, such as records, documents, catalogues and their terms, rather than how to work with it.

Uses: Node Instance, Knowledge Graph

Bootstrap terms · https://litlfred.github.io/bootstrap/0.1.0/ns#Content · defined by litlfred.github.io/bootstrap/0.1.0/schemas/graph.schema.json#/$defs/Content · source bootstrap/schemas/graph.schema.json#/$defs/Content

15. Task

A unit of work, stated by what it needs to begin and what it produces.

Bootstrap terms · https://litlfred.github.io/bootstrap/0.1.0/ns#Task · defined by www.omg.org/spec/BPMN/2.0/#task · source bootstrap/schemas/graph.schema.json#/$defs/Task

16. Actor

A person, an agent or a program that can carry out Tasks.

Uses: Task

Bootstrap terms · https://litlfred.github.io/bootstrap/0.1.0/ns#Actor · defined by www.w3.org/ns/prov#Agent · source bootstrap/schemas/graph.schema.json#/$defs/Actor

17. Skill

A Node Instance stating a responsibility an Actor carries out to complete a Task: as natural-language instructions to follow, as a contract to be tested against, or both.

Uses: Node Instance, Actor, Task

Bootstrap terms · https://litlfred.github.io/bootstrap/0.1.0/ns#Skill · defined by litlfred.github.io/bootstrap/0.1.0/schemas/graph.schema.json#/$defs/Skill · source bootstrap/schemas/graph.schema.json#/$defs/Skill

18. Role

A Node Instance naming a part an Actor takes on to carry out Tasks, and listing the Skills that part needs.

Uses: Node Instance, Actor, Task, Skill

Bootstrap terms · https://litlfred.github.io/bootstrap/0.1.0/ns#Role · defined by litlfred.github.io/bootstrap/0.1.0/schemas/graph.schema.json#/$defs/Role · source bootstrap/schemas/graph.schema.json#/$defs/Role

19. Process Node

A BPMN flow node: an activity (a task or call activity), a gateway, or an event.

Bootstrap terms · https://litlfred.github.io/bootstrap/0.1.0/ns#ProcessNode · defined by www.omg.org/spec/BPMN/2.0/#flowNode · source bootstrap/schemas/graph.schema.json#/$defs/ProcessNode

20. Sequence Flow

A directed connection in a BPMN process from one Process Node to the next.

Uses: Process Node

Bootstrap terms · https://litlfred.github.io/bootstrap/0.1.0/ns#SequenceFlow · defined by www.omg.org/spec/BPMN/2.0/#sequenceFlow · source bootstrap/schemas/graph.schema.json#/$defs/SequenceFlow

21. Process

A Node Instance holding a BPMN process that coordinates Tasks: its Process Nodes, joined by Sequence Flows, sit in lanes that each name a Role.

Uses: Node Instance, Task, Process Node, Sequence Flow, Role

Bootstrap terms · https://litlfred.github.io/bootstrap/0.1.0/ns#Process · defined by www.omg.org/spec/BPMN/2.0/#process · source bootstrap/schemas/graph.schema.json#/$defs/Process

22. Harness

A Knowledge Graph whose Subgraphs hold Skills, Roles or Processes: what an Actor uses to work with a Knowledge Graph, including itself.

Uses: Knowledge Graph, Subgraph, Skill, Role, Process, Actor

Bootstrap terms · https://litlfred.github.io/bootstrap/0.1.0/ns#Harness · defined by litlfred.github.io/bootstrap/0.1.0/schemas/graph.schema.json · source bootstrap/schemas/graph.schema.json#/$defs/Harness
