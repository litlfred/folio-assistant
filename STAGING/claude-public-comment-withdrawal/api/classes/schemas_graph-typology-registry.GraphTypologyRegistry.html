    ensureCheckout

    • ensureCheckout(repoRoot: string): void

      Ensure declared typologies/ and validators/ from repoRoot are loaded when this is an unfiltered checkout-backed registry (bean cat-tools-g7ls, owner card 2026-10-31 "A. Fix the loader").

      When readDeclaration reads an instance from a checkout outside declaredUnder — e.g. a host or sibling checkout reached from a standalone run, or a multi-instance test fixture — every discovered instance's typologies/ in that checkout (such as a document layer's glossary for an IG harness's declaration) is registered before any declaration in it is validated. No-op on a bare or filtered registry.

      Parameters

      • repoRoot: string

      Returns void
