Source of truth: this file. Open it in bpmn.io, Camunda Modeler, or any other BPMN 2.0 tool. The SVG under docs/assets/img/workflows/ is generated from it by `bun run cat render:bpmn` — never hand-edit the SVG. The <bootstrap.processes:skill> extension on an activity names the folio-assistant skill that implements it; <cat-harness.processes:bean> marks a step that reads or writes the shared work plan in beans/. Each of the six authoring tracks is a call into l2-component-edit-review.bpmn (Process_L2ComponentEditReview): the agent edits the component, checks, renders and stages it, and hands it on, while a person in the component's reviewing role reviews it alongside, never as a gate. The track's renderer, checker and reviewer are tabled in the skill l2-component-edit-review.
