    Interface FeedbackItem

    A feedback item submitted by a user or agent against a content block.

    Feedback lives in feedback/<paper-dir>/<rootName>.ts and is committed to main immediately via a git worktree, so it persists across branches.

    Extends TodoItem with authorship fields from the feedback UI.
