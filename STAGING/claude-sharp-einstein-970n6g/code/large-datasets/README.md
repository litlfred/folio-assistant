# large-datasets-id-lookup

The identifier lookup a reader uses: `lookup.js` (plain ES module, no dependencies), a one-form `index.html`, and one generated index per corpus (`who-iris/`: `manifest.json` plus JSON shards keyed by id prefix, each under 64 KiB). JavaScript, so it lives HERE and never under the plain docs pipeline, which is 'no extensions. no fancy. no js (if possible)'. The `who-iris/` index is generated by `scripts/gen-id-lookup.ts`; edit the catalogue, never the shards.

Part of [large-datasets](../README.md), declared as `large-datasets-id-lookup`, holding `code`.
