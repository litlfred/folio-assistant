Two questions, not one. catalogues / templates asks whether a .po exists at all for each extractable .pot; the string columns ask how much of the catalogues that DO exist is done. A locale can be near 100% translated across a handful of catalogues while most of its templates have none — which is why the first column is not folded into the rest.

“no basis” is not zero. A share over an empty denominator is undefined, and rendering it as 0% would report a measurement this run did not make.

One directory per table, each named. translation-sources is a graph KIND, and more than one instance may declare it; the first table measures the directory named in the subtitle, and each instance below it gets its own table for its own declared directory. They are never summed: two instances' catalogues answer two questions. A catalogue sitting in an instance that has not declared the directory is invisible here — which is a gap in that declaration rather than a locale with no work done, and the two must not read the same.

Fuzzy is counted apart from translated. A fuzzy entry has a translation and needs review; adding it to translated would flatter exactly the entries a reviewer must look at.
