# Docs index visualiser — as-is intent

**Covers:** `cat-harness/docs/cat-harness/docs-auto/index/docs/docs/index.html`. The same template renders `cat-harness/docs/cat-harness/docs-auto/index/docs/smart-trust-docs/index.html` and `cat-harness/docs/cat-harness/docs-auto/index/docs/who-iris-docs/index.html`, and this wireframe covers those as well. Generated by `cat-harness/scripts/gen-docs-auto.ts` (`bun run docs:auto`) using `autoDocPage()`, the type `index/docs`.

**Who it is for:** an author of a harness's docs, and anyone looking for which documentation pages exist. The generator's owner quote says the author "should make use of auto-doc references and provide a summary / overview". This page is the index they reuse, not the prose itself.

**What they need to do:** see every authored documentation page in a sub-graph, with the title and description its front matter declares. Then switch to a sibling sub-graph (`smart-trust-docs`, `who-iris-docs`) and follow a row to the source file on GitHub.

**What it must show** (read off the page and the generator): the title and scope tag; the derivation lede ("every AUTHORED documentation page an instance publishes …"); the "index, not the documentation" note; a sibling list with a count per sub-graph (the current one in bold, the others linked); and a two-column table, where each row holds the name (linked to GitHub), the repo path, and the declared description, or *no description in the artefact*.

## Findings

1. **Most rows say nothing.** 71 of 83 rows read *no description in the artefact*, so the table is mostly a list of paths.
2. **Non-pages are indexed as "authored documentation pages".** The six `cat-harness/docs/_includes/*.html` layout partials come first in the table, ahead of every real page.
3. **Names collide.** 14 rows are named `index` and 6 are named `agent-onboarding` (one per locale). The link text is identical, so the rows can be told apart only by the path under each name. The link list a screen reader announces is ambiguous.
4. **The YAML quotes are kept.** Ten descriptions are shown wrapped in literal quotation marks, for example `"folio-assistant — 内容无关的智能体技能框架。"`.
5. **The table cannot be searched, filtered or grouped.** Locale copies (`ar`, `es`, `fr`, `ru`, `zh`) sit among the English pages by path order. The largest sibling, `smart-trust-docs`, is a single 676-row page.
6. **The phone layout favours the path.** At 390 px the first column (`width: 26rem`, capped by the viewport) keeps about 230 px for the name and path, which leaves about 110 px for the description, so *no description in the artefact* wraps over four lines.
