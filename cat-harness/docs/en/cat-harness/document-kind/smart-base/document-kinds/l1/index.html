L1 narrative publication
description
The narrative layer of the WHO SMART Guidelines: "traditional guidelines and guidance" (Mehl 2021). Only the frame a WHO guideline and a Digital Transformation Handbook BOTH carry is here; what each puts in its body is a sub-kind — l1-guideline (recommendations, evidence, GRADE) and dth (a digital transformation handbook). Semi-fixed: these sections are required, others are allowed.
