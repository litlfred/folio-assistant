The last record, keyed `*end*`, is the stack after the whole nav: what the theme computes for a page whose link is not in it. WHY ("cache the nav"). The theme's breadcrumbs include splits the whole nav up to the page's link at every "" and walks each anchor before it: O(pages) Liquid work on every page, O(pages^2) for the site. Here the same walk is done once, over the whole nav, and each page looks its crumbs up (`components/breadcrumbs.html` in this directory). The loop body is the theme's VERBATIM. The stack before split k is exactly the theme's for the page whose link ends split k: the theme's splits of that page's prefix are the first k splits here, and the last of them differs only after the page's link, where no "" can be. A nav-category resets the stack, as the theme's `split: nav_category | last` does.
