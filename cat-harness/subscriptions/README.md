# Subscribed substrates

The root declaration of each [Knowledge Graph](https://github.com/litlfred/bootstrap/blob/main/schemas/README.md#knowledge-graph) this instance subscribes to, cached at the pinned commit: one `<id>.substrate.json` per `subscriptions` entry, holding the upstream bytes, their sha256, and the harnesses and subgraphs the substrate offers. Written by `bun run kg:subscribe`; never edited by hand.

Part of [C@T Harness](../README.md) 0.1.0, declared as `subscriptions`, holding `substrate-snapshot`.
