An agent does not arrive at a task knowing nothing. It arrives carrying
directives, memories, a record of how this person wants to be asked, and
whatever confirmations were granted in advance. All of that is **context**: it
shapes how a process runs without being part of what the process produces.

A **Context Overlay** is a set of that material applied deliberately, so the
same workflow can be run again under the same conditions — or run twice under
deliberately different ones, and the difference attributed to the context
rather than to chance.
