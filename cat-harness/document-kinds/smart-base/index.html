A document kind is a named structure of sections that a document authored with a harness follows: fixed (exactly these sections) or semi-fixed (these required, others allowed). Every kind and section names its sources.

Digital Transformation Handbook (DTH) dth

A WHO guidance publication on digitalising one area of a health system — an L1 publication whose body is a planning method rather than recommendations. It sits within the DIIG process and should use the DPI-H Reference Architecture (owner, 2026-10-01). Its domain sections map onto smart-kg L2 (DAK) classes: a DTH states for a health-system area what a DAK states for a guideline. Structure read from the three DTHs ingested in smart-base/library; a section is required only where all three have it. The Reference Architecture for DPI-H calls itself "A Digital Transformation Handbook for DPI-H" and is cited here as the architecture the others should reference.
