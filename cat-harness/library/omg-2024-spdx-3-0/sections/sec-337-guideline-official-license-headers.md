The matching guidelines apply to license and exception text, as well as official license headers. Official license headers are defined
by the SPDX License List as specific text specified within the license itself to be put in the header of files. (see explanation of
SPDX License List fields2 for more info).
The following XML tag is used to implement this guideline: <standardLicenseHeader>
