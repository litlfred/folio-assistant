Summary
A mathematical algorithm that maps data of arbitrary size to a bit string.
Description
A HashAlgorithm is a mathematical algorithm that maps data of arbitrary size to a bit string (the hash) and is a one-way function,
that is, a function which is practically infeasible to invert.
