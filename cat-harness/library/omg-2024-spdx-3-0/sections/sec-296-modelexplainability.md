Summary
Describes methods that can be used to explain the results from the AI model.
Description
A free-form text that lists the different explainability mechanisms and how they can be used to explain the results from the AI
model.
The mechanisms can be model-agnostic methods, such as SHapley Additive exPlanations (SHAP)126 and Local Interpretable
Model-agnostic Explanations (LIME)127, and model-specific methods that applied to a limited category of models.
