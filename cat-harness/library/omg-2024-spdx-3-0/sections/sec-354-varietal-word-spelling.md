C.9.1
Purpose
English uses different spelling for some words. By identifying the spelling variations for words found or likely to be found in
licenses, we avoid the possibility of a non-match due to the same word being spelled differently. This list is not meant to be an
exhaustive list of all spelling variations, but meant to capture the words most likely to be found in open source software licenses.
C.9.2
Guideline
The words in each line of the text file available at the equivalent words list3 are considered equivalent and interchangeable.
XML files do not require specific markup to implement this guideline.
