Summary
Specifies the SPDX License List version in which this license or exception identifier was deprecated.
Description
A deprecatedVersion, for a ListedLicense on the SPDX License List110 or a ListedLicenseException on the SPDX License Excep-
tions111, specifies which version release of the License List was the first one in which it was marked as deprecated.
