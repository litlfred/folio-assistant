Summary
Specifies the SPDX License List version in which this ListedLicense or ListedLicenseException identifier was first added.
Description
A listVersionAdded for a ListedLicense or ListedLicenseException on the SPDX License List120 specifies which version release
of the License List was the first one in which it was included.
