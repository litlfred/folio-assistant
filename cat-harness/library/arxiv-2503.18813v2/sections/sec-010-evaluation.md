We evaluate our design on AgentDojo (Debenedetti et al., 2024b), a recent agentic security benchmark.
We evaluate on it as it comprises a set of realistic utility and security tasks in agentic, tool-calling
scenarios. We touch upon utility, i.e., how tasks are solved by the agent with acceptable levels of
detail, and security, i.e., attacks against the agent don’t succeed in their adversarial goal.
