OPERATING MODEL
How the layers meet
An actor performs a task in a process as a role, using that role's skills.
Actor
who
A concrete participant: human, agentic or mechanical. Carries permissions across all lanes.
Task
does what
An activity in a diagram. Names the skill to run and the bean operation to perform.
Process
where
An executable BPMN diagram with DMN gateways. State is committed so sibling sessions agree.
Role
as whom
A swimlane. An actor acts as a reviewer only for the length of a lane.
Skill
knowing how
The instruction body for the task. Lives in the knowledge graph; inherited across instances.
