Summary
Provides a License author’s preferred text to indicate that a file is covered by the License.
Description
A standardLicenseHeader contains the plain text of the License author’s preferred wording to be used, typically in a source code
file’s header comments or similar location, to indicate that the file is subject to the specified License.
