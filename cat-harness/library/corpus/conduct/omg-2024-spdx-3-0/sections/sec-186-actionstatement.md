Summary
Provides advise on how to mitigate or remediate a vulnerability when a VEX product is affected by it.
Description
When an element is referenced with a VexAffectedVulnAssessmentRelationship, the relationship MUST include one actionState-
ment that SHOULD describe actions to remediate or mitigate the vulnerability.
