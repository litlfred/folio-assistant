Profile is the term for a compliance point within the SPDX community across The Linux Foundation and OMG. The System
Package Data Exchange (SPDX) specification defines the following nine compliance points, defined as “Profiles”:
• Core Profile
• Software Profile
• Security Profile
• Licensing Profile
• Dataset Profile
• AI Profile
• Build Profile
• Lite Profile
• Extension Profile
The Core Profile is mandatory. All others are optional.
