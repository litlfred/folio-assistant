Summary
Describes the type of the given dataset.
Description
Describes the datatype contained in the dataset.
For example, a dataset can be an image dataset for computer vision applications, a text dataset such as the contents of a book or
Wikipedia article, or sometimes a multimodal dataset that contains multiple types of data.
