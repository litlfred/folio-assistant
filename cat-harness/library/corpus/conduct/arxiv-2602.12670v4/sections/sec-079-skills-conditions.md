Each task in the latest aggregate is evaluated under two matched conditions:
• No Skills: The agent receives the task instruction (the task.md body) and task data, but no
environment/skills/ content is present.
• Curated Skills: The complete environment/skills/ directory is available, including SKILL.md
files, examples, scripts, and references.
A third condition, self-generated Skills, is evaluated on the three dedicated-harness configurations
and reported separately (Appendix D.6); it is not part of the two-condition aggregate in Table 2.
