Antigravity 2.0 skill locations
Antigravity 2.0 loads skills from two primary locations:
Location
Scope
<workspace-root>/.agents/skills/<skill-folder>/
Workspace-specific
~/.gemini/config/skills/<skill-folder>/
Global (all workspaces)
Workspace skills: scoped to a single project and committed to version control to share
across your engineering team.
Global skills: available across all projects on your workstation.
Invoking skills in Antigravity 2.0
Autonomous invocation: the agent automatically reads and follows relevant skills based
on your prompt.
Manual slash command: type /<skill-name> in the prompt panel to explicitly invoke a
skill.
