- **Study Design:** Controlled experiment ($n = 68$: **45 novices** and **23 experts**) testing **colour-based operator/gateway matching** (colouring corresponding split and join gateways with matching background colours via SESE / RPST decomposition, Section 3 pp. 8–12) against uncoloured monochrome Petri net / workflow models across **4 real-world models (Models A–D)** with **5 comprehension questions per model (20 questions total)** (Table 2, p. 16).
- **What Was Measured:**
  - **Comprehension Accuracy (`SCORE`):** number of correct answers out of 5 per model (and out of 20 overall).
  - **Comprehension Speed (`TIME`):** completion time in minutes per model.
- **Numeric Thresholds & Key Findings:**
  - **Overall Accuracy Gain (Table 5, p. 20):** Highlighted models achieved significantly higher comprehension accuracy overall (**mean $15.79 / 20$ [79.0%] vs. $14.24 / 20$ [71.2%]**, $+7.8	ext{ percentage points}$, $t	ext{-test } p = 0.015$).
  - **Novice vs. Expert Breakdown (Table 5, p. 20):**
    - **Novices ($n = 45$):** Highlighted accuracy **$15.61 / 20$ (78.1%) vs. $13.36 / 20$ (66.8%)** unhighlighted (**$+11.3	ext{ percentage points}$**, $p = 0.004$) — novices with syntax highlighting outperformed unhighlighted experts ($15.61$ vs. $15.50$)!
    - **Experts ($n = 23$):** Accuracy **$16.18 / 20$ vs. $15.50 / 20$** ($p = 0.258$, ceiling effect on accuracy), **but experts answered significantly faster on highlighted models**: total completion time **$15.82	ext{ min}$ vs. $18.67	ext{ min}$** ($-15.3\%$ time reduction, $p = 0.043$, Table 5 p. 20).
  - **Model-by-Model Effect (Table 5, p. 20):** Significant accuracy improvements on complex/unstructured models **Model B** ($4.12$ vs. $3.55$, $p = 0.018$) and **Model C** ($4.00$ vs. $3.38$, $p = 0.008$).
