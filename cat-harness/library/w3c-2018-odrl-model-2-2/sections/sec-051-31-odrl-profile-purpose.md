The ODRL Information Model serves as the core framework and vocabulary to express policies. The ODRL Core Vocabulary
[odrl-vocab] articulates this set of vocabulary terms. An ODRL policy may be expressed using the ODRL Core Vocabulary, and
this represents the minimally supported policy expression.
An ODRL Profile MUST be defined to provide vocabulary terms (as scoped in the ODRL Profile Mechanism section) that can be
used in ODRL policies requiring additional semantics. An ODRL Profile explicitly serves community needs by specifying the
vocabulary terms they require to be supported in ODRL policy expressions. These terms may be defined explicitly or may be
adopted from the ODRL Common Vocabulary.
The ODRL Common Vocabulary [odrl-vocab] provides a generic range of common actions for Permissions, Prohibition, and
Duties as well as Policy subclasses, Constraint left operands and operators, Asset relations, and Party functions.
