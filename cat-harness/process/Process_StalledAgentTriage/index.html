nameStalled-agent triage & bidirectional relay re-entry
summaryWhen agents stall (quota exhausted, context full, container lost, session timed out) OR when an agent returns on its next turn after another session advanced the repository, execute Bidirectional Relay Continuity: reconcile remote commits and epic write-ahead…
descriptionWhen agents stall (quota exhausted, context full, container lost, session timed out) OR when an agent returns on its next turn after another session advanced the repository, execute Bidirectional Relay Continuity: reconcile remote commits and epic write-ahead snapshots, classify open and draft PRs, inspect worktrees, /tmp overlays, and Cargo/Lean donor caches non-destructively (never git reset --hard; rescue dirty unpushed work onto claude/salvage-* or resume in place), consolidate workstreams into 2-4 themes when owner triage is needed, reconcile the epic lease table on cat/cat-harness/beans, and re-route ready PRs through the Merge Steward. Operating skills: stalled-agent-triage, handover-report, prepare-for-handover, agent-handoff, bean-coordination, coordinate, merge-manager-watcher.
enforcementstrict
