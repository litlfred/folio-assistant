nameClose the bean
summaryThe closing half of every bean's life: end it in a state that says why.
descriptionThe closing half of every bean's life: end it in a state that says why. Done work is completed and archived; unwanted work is scrapped with its reasons — never deleted — and archived; blocked work records what it waits on and goes back to `todo` for whoever can act. Called, never run on its own, straight before an end event of a process that called Process_BeanOpen. A bean is never deleted. A scrapped bean stops the next agent re-entering a dead end; a deleted one leaves a sibling unable to tell abandonment from accident.
enforcementstrict
