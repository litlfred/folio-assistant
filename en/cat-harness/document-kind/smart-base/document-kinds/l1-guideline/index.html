title
WHO guideline (L1)
description
An L1 publication containing recommendations for clinical practice or public health policy, structured as the WHO Handbook for Guideline Development (2nd ed.) §12.1 "Guideline format" requires, with the SMART additions Mehl 2021 names: uniquely identified recommendations and data recommendations. Sections modelled by smart-kg L1 classes are the ones a smart-kg L1 graph of the guideline holds (bean 8pzh).
