Retrieve a remote Knowledge Graph via npm package or tarball

Retrieve and inspect a remote Knowledge Graph packaged as an npm package or tarball (.tgz), supporting both unhydrated source graph views (authored declarations, skills, schemas) and hydrated materialized graph views (subgraph JSON-LD, metadata indexes, dereferenced graph projections).

Skills it satisfies

A skill states the capability; this Tool is one way to exercise it. Each skill’s declared input and output contract follows, where it has one.

npm-kg-distribution

Package, release, distribute, and retrieve Knowledge Graphs using npm tooling and tarballs: declare package.json as an authored pre-packaging asset in the Knowledge Graph, build .tgz packages via bun pm pack, record publications as folio-binary-release/v1 state documents hosted on GitHub binary releases, and retrieve remote Knowledge Graphs using npm install for both unhydrated source graph and hydrated materialized graph views.

Source: cat-harness/skills/kg/kg-core/npm-kg-distribution.md.

Also satisfied by: ci-publish-subgraph-index, npm, pack-tarball, package-release-manual, package-release-workflow, subgraph-index-package.

The skill declares no I/O contract (schemas/skills/npm-kg-distribution/{input,output}.schema.json).

remote-mount

Bring a harness, and every layer it depends on, into a checkout that does not hold it, from another repository at a pinned commit, as declared directories with a lock: a source.remote entry in the downstream’s root index.config.json (legacy: remoteMounts on its declaration) and mountDefaults on the harness. Covers when to mount and when to subscribe instead, why there are no submodules and no .deps/, the transitive closure through needs and gitlinks, overrides by id, the lock, and the three states.

Source: cat-harness/skills/kg/kg-core/remote-mount.md.

Also satisfied by: build-instance-site, index-config-migrate, instantiate-harness, mount-from-lock, npm, subgraph-index-package.

The skill declares no I/O contract (schemas/skills/remote-mount/{input,output}.schema.json).

How it is deployed and reached

  • Command line. From the repository root: bun run cat kg:retrieve:npm. cat kg:retrieve:npm runs bun run cat-harness-tools/scripts/kg-retrieve-npm.ts (declared in cat-harness-tools/package.json).
  • GitHub Actions. No workflow in this checkout runs its command.

As an API: its operation in the OpenAPI document and the MCP tool list of its layer.
