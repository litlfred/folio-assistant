descriptionScripts this layer runs. `lib/roots.ts` is the one place that names the three roots a file can mean (HARNESS_ROOT, TOOLS_ROOT, REPO_ROOT). `gen-id-lookup.ts` builds the prefix-sharded lookup over a catalogue's REFERENCED nodes for every instance that declares an `id-lookup` directory, and writes it THERE (`bun run cat id-lookup`, gated by `id-lookup:check`); `bench-id-lookup.ts` measures it at full catalogue scale on a seeded synthetic corpus. Neither names a corpus: both read the checkout's declarations. `extract-assets.ts` is the tool behind the harness's `asset-extraction` skill: it turns a container's INDEX into a `folio-extraction/v1` record, whose contract is `schemas/content/extraction.ts`.
