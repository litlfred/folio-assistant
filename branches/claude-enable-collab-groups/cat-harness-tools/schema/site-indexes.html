Description

The published index files the site's viewers read — each $schema family typed, so the graph-typology registry names a validator instead of the script that writes it.

Every schema here was taken from what its writer emits and cross-checked against the committed file, so it describes the file as written.

Two conventions hold throughout, because the writers share them:

  • JSON.stringify drops undefined, so a TypeScript x?: T is an ABSENT key, never null. Where the file does carry null it is modelled as .nullable(), and nowhere else.
  • tile is the navbar count every generated index carries, typed once by TileCountsSchema and reused here.

Objects are .strict(): these files are generated, so a key nobody declared is a writer that changed without its schema.
