Description

A decision handed to a person, as a shape rather than as a habit.

Enforces the interaction-modality (§4) and decision-comparison skills: the options are compared in prose, one is recommended, and the question says what happens if nobody answers.

There are no optionals below. A decision with three options and two comparisons does not parse; one with no ifSilent does not parse; one whose recommendation names an option that is not in the list does not parse — the same technique as WaiverNodeSchema.

One object renders BOTH halves — renderDecision emits the prose table, and the same options array is what a selection tool is given — so the table and the offered choices cannot drift apart.

It checks that the question was asked, never that the answer is honest: it cannot tell a good con from a lazy one.
