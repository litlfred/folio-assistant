Description

The shared I/O type vocabulary Tool ports reference.

ToolDefinition.io.*.schema is an absolute IRI, so the types it names have to exist somewhere fetchable. This is that somewhere: one published JSON Schema per type (tool-types/<Name>.schema.json) and a combined document of $defs, generated from Zod like every other schema here.

A shared document rather than a schema per tool

A Task's inputs are checked against the Tool that will execute it, so two tools satisfying one skill — beans-cli and beans-manual — must declare the same input type for "these are interchangeable" to be verifiable. A shared $defs makes that identity rather than a structural comparison.

It is also what mcp-contract checks against: a served MCP tool's inputSchema must agree with the Tool node's io, and agreement is only decidable if both sides name the same type.
