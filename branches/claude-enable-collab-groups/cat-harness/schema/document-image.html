Description

An image placed on a page of an ingested document.

Every image carries a role and its basis

Most placed images in an ingested corpus are page scans — one near-full-bleed image per page, which is the page itself — not figures. So every entry carries a ImageRole, and the basis for it: coverage and imagesOnPage are the two numbers the verdict was computed from, stored so a reader can check it rather than believe it.

The third state is undetermined, and it is not scan

A role is only ever page-scan or figure when the geometry was actually read. A backend that could not place an image yields undetermined, never a default — an image wrongly filed as page-scan is silently dropped from every description pass.
