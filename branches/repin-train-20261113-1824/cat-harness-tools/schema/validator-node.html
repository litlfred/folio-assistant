Description

A VALIDATOR as a node of the knowledge graph. The validator names the family it validates, so the harness that writes the code declares what it checks, and a kind lists only its $schema families.

Declared in a validators/ graph of the harness whose code it references. The registry joins each node onto the kind it names: a kind's family with no validator of its own takes the node's schema. A node naming a kind or a family the kind does not list is refused, and so is a second answer for a family that already has one.

id, not name: a JSON file whose name equals its stem is how findDeclarationFile recognises a LAYER declaration.

A LEAF: Zod only.
