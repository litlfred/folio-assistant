Description

The deployment resolver: for each task of a process, who may run it in a deployment, and with which Tool.

It reports, and never fails

"A task no placement can run" appears in the report and never blocks a merge. This module returns a report and has no gate; a caller must not turn a finding into an exit code.

A pure function over what the caller reads

It takes the description, the actors, the tasks and the Tools as values and reads no files; the tools layer reads the process and Tool graphs.

What it can decide, and what it says it cannot

| Tool requirement | decided from | |---|---| | requires.network: true | the placement's reach, through effectiveReach. Unknown reach does NOT satisfy it: an unknown is routed like air-gapped (actor-reach.ts). | | requires.os, requires.runtime | nothing yet. A placement does not declare an OS or a runtime, so these are reported as could not determine, never as satisfied. |

A Tool with no requires works for every placement.

A skill with no Tool is judgement, not a gap

Most skills have no Tool node; they are exercised by the actor in the lane (check:tools reports uncovered skills and does not fail on them). Only a skill that HAS Tools is judged, and a task is held up only when every Tool of one of its skills fails for every candidate. A skill with no Tool is listed under judgement, never counted against the task.
