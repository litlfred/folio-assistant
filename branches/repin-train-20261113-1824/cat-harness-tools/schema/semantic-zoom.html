Description

When a card stops rendering its words and becomes its avatar.

As the board shrinks, a card stops rendering its words and renders its avatar instead. The threshold is declared data, not a literal in the renderer.

Folio default, a kind may override

This repository's inheritance rule, unchanged: the folio always has a number, every kind resolves to one, and a kind that states nothing is complete rather than invalid — requiredness is checked after resolution, never on the declaration.

An override CITES WHY, and the resolver says where the number came from

because is required on an override, and zoomThresholdFor returns the source alongside the value, so a reviewer can tell a deliberate override from the default.

It is not an entity. ZoomThreshold has no identifier of its own and cannot exist apart from the folio or the kind that states it.

PIXELS, not board units

Legibility is a property of what reaches the reader's eye, so the threshold is the card's RENDERED width in CSS pixels, after zoom — unlike board-positions.ts, which stores board units so a file does not bake in a viewport.
