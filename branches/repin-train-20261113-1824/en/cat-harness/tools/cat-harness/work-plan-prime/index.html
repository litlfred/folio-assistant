Skills it satisfies

A skill states the capability; this Tool is one way to exercise it. Each skill’s declared input and output contract follows, where it has one.

todo-manager

Maintain and display work-in-progress task lists using the beans CLI issue tracker. Track implementation progress, open tasks, missing artifacts, and blocked items across a session.

Source: cat-harness/work-plan/skills/work-plan/todo-manager.md.

Also satisfied by: bean-query, beans-cli, beans-manual.

The skill declares no I/O contract (schemas/skills/todo-manager/{input,output}.schema.json).

bean-coordination

Pointer to the bean-based session work-plan system (the beans CLI flat-file issue tracker, data under beans/). Operational usage lives in todo-manager.md / session-intent.md; this file is the canonical copy of the coordinator logic that downstream repositories sync from.

Source: cat-harness/work-plan/skills/work-plan/bean-coordination.md.

Also satisfied by: bean-claim-check, bean-query, beans-cli, beans-manual, drain-queue, open-work-lookup, sibling-sessions, workflow-complete, workflow-start.

The skill declares no I/O contract (schemas/skills/bean-coordination/{input,output}.schema.json).

session-intent

Session-start intent declaration + session-end results recording, against the work plan’s goals (milestone work items) and their open work items. Enforces the durable-handoff discipline so any agent can pick up another’s thread.

Source: cat-harness/sdlc/skills/sdlc-core/session-intent.md.

Also satisfied by: beans-cli, beans-manual.

The skill declares no I/O contract (schemas/skills/session-intent/{input,output}.schema.json).

pending-show

Show the current session’s pending work — work items list + ledger intent. Read-only.

Source: cat-harness/sdlc/skills/sdlc-core/pending-show.md.

Also satisfied by: beans-cli, beans-manual.

The skill declares no I/O contract (schemas/skills/pending-show/{input,output}.schema.json).

How it is deployed and reached

  • Command line. From the repository root: beans prime.
  • MCP. Served as work_plan_prime by sage (cat-harness-tools/scripts/sage-mcp.sh), google-drive (cat-harness-tools/scripts/google-drive-mcp.sh), folio-assistant (bun run cat-harness-tools/src/index.ts --stdio --repo .), the servers .mcp.json declares.
  • In process. src/tools/beans-prime.ts — loaded by the harness directly, with no server.
  • GitHub Actions. No workflow in this checkout runs its command.

The MCP tool it serves, as tools/list answers:

work_plan_prime — read from its registrar.
