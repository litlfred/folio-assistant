OpenAPI viewer

Render every OpenAPI document a layer’s openapi graph holds at the visualiser’s route: a hub, a page per layer listing its documents, and a page per document and per operation, drawn from the document copied beside them.

Skills it satisfies

A skill states the capability; this Tool is one way to exercise it. Each skill’s declared input and output contract follows, where it has one.

graph-rendering

Draw any graph in a harness (schemas, processes, a folio’s block graph and any formal relation its content type adds, a detangle partition) so the picture is derived, checkable and readable. Ten rules, which engine to lay a graph out with and why, and how each graph typology here applies them.

Source: cat-harness/skills/kg/graph-management/graph-rendering.md.

How it is deployed and reached

  • Command line. From the repository root: bun run cat openapi:viz. cat openapi:viz runs bun run cat-harness-tools/openapi/scripts/gen-openapi-viewer.ts (declared in cat-harness-tools/package.json).
  • GitHub Actions. No workflow in this checkout runs its command.
