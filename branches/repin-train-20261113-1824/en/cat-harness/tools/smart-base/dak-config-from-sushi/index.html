Skills it satisfies

A skill states the capability; this Tool is one way to exercise it. Each skill’s declared input and output contract follows, where it has one.

dak-preprocessing

What each DAK pre-processing step does before the IG Publisher runs, which steps exist only to feed the Publisher’s page index, and how the phase runs as the overlay on fhir-harness’s AST cache refresh (dak-pre-export.sh). Also which files in a DAK repository are authored and which are generated, and the SEMVER rule for DAK and IG versions. Read before changing, assuming or moving a pre-processing step.

Source: smart-base/skills/content/authoring-who-smart-guidelines/dak-preprocessing.md.

Also satisfied by: dmn-to-html, dmn-to-questionnaire.

The skill declares no I/O contract (schemas/skills/dak-preprocessing/{input,output}.schema.json).
