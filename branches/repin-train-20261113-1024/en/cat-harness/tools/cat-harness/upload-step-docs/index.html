The upload step, from its Tools

Render document ingestion’s FIRST step as a reference page, generated from the Tool nodes that implement it: the step, its lane and role, its skill and every Tool whose satisfies names that skill, with each Tool’s description, installation, invocation, typed ports and selection triple. Everything but the process file’s own path is derived — the start event, the activity its single outgoing flow reaches, and that activity’s skill — so a step inserted, renamed or re-pointed moves the page rather than staling a literal. Refuses rather than emitting a partial page when the start event flows nowhere or to more than one place, when the first step is not an activity, when it names no skill or several, or when NO Tool satisfies that skill — the last because an empty page reads as a documented absence of mechanism, which is a finding rather than a document.

Skills it satisfies

A skill states the capability; this Tool is one way to exercise it. Each skill’s declared input and output contract follows, where it has one.

docs-generation

How a checkout of this harness generates and publishes its docs site: regenerating derived references, composing the docs layers and each layer’s site into one Jekyll source, building it with just-the-docs, the post-build passes, the TypeDoc API reference, the knowledge-graph export, and the full-replace publish to gh-pages and its branches/ previews.

Source: cat-harness/skills/ui/ui-core/docs-generation.md.

Also satisfied by: bpmn-checklist, bpmn-render, ci-post-merge-regen, pages-index, pages-publish, readme-audit, readme-sync, render-order, schema-docs, shared-assets, site-build-local, site-search-index, site-search-scopes, skill-docs, subgraph-readmes, stage-ig-sites, proof-dependency-graph.

The skill declares no I/O contract (schemas/skills/docs-generation/{input,output}.schema.json).

How it is deployed and reached

  • Command line. From the repository root: bun run cat upload-step:docs. cat upload-step:docs runs bun run cat-harness-tools/scripts/gen-upload-step-docs.ts (declared in cat-harness-tools/package.json).
  • GitHub Actions. No workflow in this checkout runs its command.
