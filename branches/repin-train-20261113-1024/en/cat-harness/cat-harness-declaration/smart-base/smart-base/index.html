_comment
The WHO SMART Base layer: the knowledge-graph assets of the WHO SMART Guidelines base — the ingested WHO digital-health corpus, the methodologies read out of it, and the voices derived from it. It takes no position on the DAK/IG pipeline layering. The upstream toolchain is not vendored here: `WorldHealthOrganization/smart-base` stays the home of its ~54 Python scripts, and `smart-base-tools` wraps them.

_needs_comment
`needs` governs the layer order: `dependency-order.ts` sorts on it and `harness-tiles.ts` builds the navbar spine from it. smart-base needs `fhir-harness` (the layer below) and `who-iris`, which holds the WHO IRIS publications its voices, methodologies and l1-extraction cite. `needs` does not compose the skill or content overlay: that is `dependencies.folioAssistant` in `<name>.config.json`, walked by `resolveSkillDirs`. No `smart-*` instance declares config dependencies, so `resolveSkillDirs` returns each instance's own skills only.
