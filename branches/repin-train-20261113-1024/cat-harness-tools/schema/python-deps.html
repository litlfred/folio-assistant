Description

The Python packages this repository's scripts need — declared once.

E.g. pdf-structure.py imports pymupdf, pdf-ocr.py shells to tesseract, image extraction wants pypdf + Pillow. A Python tool can only be tested in CI if CI installs its backend, so every such need is declared here.

Authoritative here, requirements*.txt generated

The TypeScript is definitional and the published artefact is downstream (directory-conventions §"What lives in the schemas graph"). A flat requirements.txt cannot carry which import name a distribution provides, or why a declared package has no import at all, so it is the OUTPUT, not the source.

Two tiers

| set | wheels | size | |---|---|---| | lean | 12 wheels | 144 MB | | lean + extended | 16 wheels | 467 MB |

extended is camelot-py and what it pulls transitively (numpy, pandas, OpenCV), for ONE script — pdf-tables.py — so it is installed separately. The sizes were measured with a warm cache; a cold CI runner pays more.
