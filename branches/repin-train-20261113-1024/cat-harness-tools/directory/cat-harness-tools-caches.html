titleCI caches
descriptionThe CI caches this layer declares (cache-first CI, rule 6): one `cache/1.0.0` node per cache in this layer's reusable workflows and scripts (`layer-pr-checks.yml`, `pr-tests.yml`), with its key recipe, trust class, location, producer, consumers, save policy, verify and uses; and `cache-inventory/1.0.0` snapshots of the caches found across the harness repositories, dated, which are never read as declarations. `viewer.md` is generated by `bun run cat caches:viz` and held current by `caches:viz:check`; it computes the key today's pins imply and joins the stored key, size and hit rate from the daily cache report, so staleness is computed, never claimed.
