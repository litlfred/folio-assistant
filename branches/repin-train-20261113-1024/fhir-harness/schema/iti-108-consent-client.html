Description

IHE ITI-108 (Find Access Consent / Access Consent [ITI-108]) Consent Registry read client for IHE Privacy Consent on FHIR (PCF) 1.1.0 and HL7 FHIR R4 Consent.

Queries a FHIR R4 Consent Registry (GET [base]/Consent with ITI-108 search parameters patient, patient.identifier, status=active, actor, purpose, category, security-label, date, action, source-reference, _profile), validates the returned searchset Bundle, filters out non-active, expired (provision.period.end < now), and not-yet-valid (provision.period.start > now) Consent resources (as well as OperationOutcome informational entries), and returns a three-valued result:

  • status: "determined" with active, non-expired Consent resources when the registry responds with a valid searchset Bundle;
  • status: "unknown" (never silent empty and never permit) with a diagnostic reason when the registry is unreachable, times out, returns a non-2xx HTTP status, or returns malformed JSON / a non-searchset payload.

Follow-up bean folio-assistant-6jnx: - FhirConsentSchema, FhirSearchsetBundleSchema, FhirOperationOutcomeSchema, parseFhirPeriodBound, and isConsentExpired are imported from ./pcf-consent.js (built from hl7.fhir.r4.core#4.0.1 StructureDefinition-*.json and CodeSystem-*.json, with a single isConsentExpired definition).
