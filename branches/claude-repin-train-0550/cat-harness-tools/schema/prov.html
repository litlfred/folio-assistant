Description

W3C PROV-O: the record of a task or decision being performed, extended for computable Data Sharing Agreements.

The deterministic BPMN engine checks a policy BEFORE a task and refuses; the agentic swarm acts, and a QA/QC report checks the policy AFTER, from this log (docs/agentic-harness.html#bpmn-execution). Both need the same record, so it is PROV-O's, not ours.

One prov:Activity per task run or decision:

| PROV-O / extension | means here | |---|---| | prov:qualifiedAssociation.prov:agent | the Actor that performed it | | prov:qualifiedAssociation.prov:hadRole | the Role it acted in (the lane's) | | prov:qualifiedAssociation.prov:hadPlan | the BPMN task: <process>#<task id> | | prov:actedOnBehalfOf | the person an agent worked for | | prov:used / prov:generated | the graph nodes read and written | | prov:wasInformedBy | the activity this one was part of: a Tool activity names its workflow step's | | prov:used → dcat:Distribution + spdx:checksum | the DSA agreement text the decision was made under (DCAT 3) | | prov:used → cred:VerifiableCredential | the grant, by its W3C VC Data Model 2.0 credential id | | cat-harness:underPolicy | the ODRL policy (or policies) it acted under | | cat-harness:previousHash | local extension: SHA-256 hex digest of the preceding record in the chain (null at genesis) | | cat-harness:recordHash | local extension: SHA-256 hex digest of this record's canonical JSON |

hadPlan is PROV-O's term for "the plan an agent followed", which a BPMN task is.

The agreement and the grant use existing open terms. The agreement is a prov:used entity whose @id is the DCAT 3 dcat:Distribution of its legal text, carrying that text's spdx:checksum (spdx:algorithm + spdx:checksumValue). The grant is a further prov:used entity whose @id is the W3C VC Data Model 2.0 credential id.

The hash chain is a local extension. No open standard defines a hash-chained PROV log, so cat-harness:previousHash and cat-harness:recordHash stay in the cat-harness: namespace and are described as such (PROV_LOCAL_EXTENSION_TERMS), in this module, in the PROV-JSONLD emitted by prov-jsonld.ts, and nowhere passed off as PROV.
