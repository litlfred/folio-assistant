Description

The change-size rule: thresholds, basis, and prose/KG versus code weighting.

A report-only advisory limit of ~400 lines of non-generated, non-lockfile code, prose and KG documentation weighted lower; it becomes a blocking CI gate once calibrated against PR history.

Modeled after test/health/ thresholds: every threshold structurally carries its basis (source and reasoning), so a check cannot ship a bare constant.

Prose & Knowledge Graph vs Code

Prose and KG documentation read linearly and are easier to adjudicate than code, so they are weighted at 0.25x (or 4x the allowance): 1 line of prose/KG documentation = 0.25 effective lines.

Mechanical and Generated Exemptions

Excluded from the effective line count: - Lockfiles (bun.lock, package-lock.json) - Machine-generated files / build artifacts (*.jsonld, *.qa.json, etc.) - File renames and migrations with recorded justification

Reporting Format

Report as a count with its denominator, never as a bare percentage (e.g., "4 of 32 PRs (12.5%) exceeded the threshold").
