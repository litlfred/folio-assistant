    Module schemas/kg/memory-record

    The memory record: the base every kept memory shares, and the layer a bean extends — a bean is a memory note with additional structure for process, role and the like.

    layerkindadds
    the shared coreMemoryRecordCoreKind (mixin)id, title, tags, timestamps
    a memory recordMemoryRecordKind memory-record/1.0.0scope, about, structured entries
    a beanbean/1.0.0 (schemas/sdlc/bean-graph.ts)status, type, priority, parent, blocking

    A bean extends the core rather than memory-record/1.0.0 itself, so the bean's own file format is unchanged: its entries are the lines of its body that parseEntryLine reads, and its scope is always item. The store interface is layered the same way: WorkPlanStore extends MemoryStore (src/workflow/work-plan-store.ts).

    The curated agent memory (the memory kind, "read during a process, never written by one") is a different thing and stays separate.
