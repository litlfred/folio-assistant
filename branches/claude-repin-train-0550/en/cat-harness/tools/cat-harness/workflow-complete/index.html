Complete a step

Record an enabled step as done — or supply the facts a decision gateway is computed from — and advance the layer. Refuses a step that is not enabled.

Skills it satisfies

A skill states the capability; this Tool is one way to exercise it. Each skill’s declared input and output contract follows, where it has one.

process-state

Track where you are inside a running process — which task, in which swimlane, under which role — and recover deliberately when you find yourself outside it. Read before completing a workflow step, and whenever something unexpected interrupts one. Covers what to do about notes and stickies you re-anchored while off-process, which leave no trace in the artefact.

Source: cat-harness/skills/process/workflow/process-state.md.

Also satisfied by: workflow-gate, workflow-list, workflow-next, workflow-start, bpmn-engine.

The skill declares no I/O contract (schemas/skills/process-state/{input,output}.schema.json).

bean-coordination

Pointer to the bean-based session work-plan system (the beans CLI flat-file issue tracker, data under beans/). Operational usage lives in todo-manager.md / session-intent.md; this file is the canonical copy of the coordinator logic that downstream repositories sync from.

Source: cat-harness/work-plan/skills/work-plan/bean-coordination.md.

Also satisfied by: bean-claim-check, bean-query, beans-cli, beans-manual, drain-queue, open-work-lookup, sibling-sessions, work-plan-prime, workflow-start.

The skill declares no I/O contract (schemas/skills/bean-coordination/{input,output}.schema.json).

How it is deployed and reached

  • MCP. Served as workflow_complete by sage (cat-harness-tools/scripts/sage-mcp.sh), google-drive (cat-harness-tools/scripts/google-drive-mcp.sh), folio-assistant (bun run cat-harness-tools/src/index.ts --stdio --repo .), the servers .mcp.json declares.
  • In process. src/tools/workflow.ts — loaded by the harness directly, with no server.
  • GitHub Actions. No workflow in this checkout runs its command.

The MCP tool it serves, as tools/list answers:

workflow_complete — read from its registrar.
