Draw a document’s tables and figures from its ArchiMate data, and check the model against the document’s relationship rules

For each table a layer’s cat-archimate.config.json lists under tables, rewrites the block’s Markdown table from an archimate-relationship-rules/v1 file (relationship-rules: source, relationship, target, note; relationship-types: picture, verb, meaning), keeping the caption and footnotes. For each figure under figures that names an svg, writes the view as SVG (the same drawing as the view’s page). For a rules table that names a model, reports the rules the model never uses, the relationships no rule covers, the rules ArchiMate’s relationship table refuses, and the relationship types the rules use without a meaning. The rules are in charge: nothing is rewritten from the model.

Skills it satisfies

A skill states the capability; this Tool is one way to exercise it. Each skill’s declared input and output contract follows, where it has one.

archimate-models

ArchiMate models as knowledge-graph content: how a layer declares the Archi models it holds, what the archimate subgraph gives every model, view, element and relationship (an IRI, a thin page, and every view drawn as SVG from the model’s own diagram, and its metamodel derived and checked), how to version the models, how to wire them into a folio’s staging build and navbar, how to count and lower the crossed lines in a view before committing it, why every view carries a plain-language key, why names are the source’s own terms linked to their SKOS concepts, and why no Java, no Archi CLI and no Archi HTML report is ever part of the pipeline. Read before adding, authoring, publishing or rendering an .archimate file, before citing an ArchiMate element from prose, and before reaching for Archi’s own tooling in CI.

Source: cat-harness/skills/ui/ui-core/archimate-models.md.

Also satisfied by: archimate-actors, archimate-check, archimate-crossings, archimate-detangle, archimate-metamodel, archimate-pages.

The skill declares no I/O contract (schemas/skills/archimate-models/{input,output}.schema.json).

How it is deployed and reached

  • Command line. From the repository root: bun run cat archimate:blocks. cat archimate:blocks runs bun run cat-harness-tools/archimate/scripts/archimate-blocks.ts (declared in cat-harness-tools/package.json).
  • GitHub Actions. No workflow in this checkout runs its command.
