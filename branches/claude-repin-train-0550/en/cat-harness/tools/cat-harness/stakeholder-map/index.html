Skills it satisfies

A skill states the capability; this Tool is one way to exercise it. Each skill’s declared input and output contract follows, where it has one.

role-model

Actors, roles and skills — who performs a BPMN task, under which swimlane, with which skills. How a role’s skill set is resolved through inherits and through a subprocess call chain, how a lane binds to a declared role, and how kg:audit finds a dangling skill, lane, role or decision.

Source: cat-harness/skills/process/process-core/role-model.md.

The skill declares no I/O contract (schemas/skills/role-model/{input,output}.schema.json).

How it is deployed and reached

  • Command line. From the repository root: bun run cat stakeholder-map. cat stakeholder-map runs bun run cat-harness-tools/scripts/stakeholder-map.ts (declared in cat-harness-tools/package.json).
  • MCP. Served as stakeholder_map by sage (cat-harness-tools/scripts/sage-mcp.sh), google-drive (cat-harness-tools/scripts/google-drive-mcp.sh), folio-assistant (bun run cat-harness-tools/src/index.ts --stdio --repo .), the servers .mcp.json declares.
  • In process. src/tools/stakeholder-map.ts — loaded by the harness directly, with no server.
  • GitHub Actions. No workflow in this checkout runs its command.
