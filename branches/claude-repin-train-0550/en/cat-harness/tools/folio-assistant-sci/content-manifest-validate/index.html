How it is deployed and reached

  • Command line. From the repository root: bun run cat content:validate. cat content:validate runs bun run cat-harness-tools/pipeline/validate.ts (declared in cat-harness-tools/package.json).
  • GitHub Actions. No workflow in this checkout runs its command.
