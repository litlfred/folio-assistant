Reuse-first terminology and code-list lookup

Look up a concept or code token for a semantic slot across the four reuse-first rungs of the terminology-coding methodology: (1) the target guide’s l1-scenario-vocabulary/v1; (2) smart-base’s generic personas (DAK.Persona.*), GRADE code-lists/*.json and the guideline-domain SKOS glossary; (3) local WHO/ILO FSH CodeSystems (ISCO08, CDHIv2, CDHIv1, CDSCv2, KGTerminologySystem); (4) a proposed glossary-terms candidate (status: "candidate"), or could-not-determine for business-process.

Skills it satisfies

A skill states the capability; this Tool is one way to exercise it. Each skill’s declared input and output contract follows, where it has one.

classify-and-code-content

Classify and code L1 narrative content (recommendations, implementation practices, remarks, and proposed coverage exclusions) and L2 DAK slots (personas, business processes, guideline domains, conditions, interventions, medicines, and GRADE ratings) using the terminology-coding methodology and the terminology-lookup Tool. Covers the authoring-agent’s four-rung reuse-first lookup, the l1-extraction-reviewer lane that reads and signs proposed L1 coverage exclusions against the printed page, and the terminologist / ontologist lane that adjudicates candidate codings and local glossary candidates.

Source: smart-base/L1/skills/smart-l1/classify-and-code-content.md.
