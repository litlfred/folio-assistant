Authored L1 → verbatim against transcriptions and image narratives

Check authored L1 (*.l1.yaml, the measles pattern) for a source with no usable text layer: each statement must be verbatim in the image narrative (images.json) or the transcription block it names; every transcription word (digits aside) must be corroborated by the entry’s text layer unless listed under inspectionOnly; keys must be unique.

Skills it satisfies

A skill states the capability; this Tool is one way to exercise it. Each skill’s declared input and output contract follows, where it has one.

transcription-verbatim

Check L1 authored from pictures (a schedule poster, a slide deck: a source with no usable text layer) against the image narratives and transcriptions it names: every statement verbatim in one of them, every transcription word corroborated by the entry’s text layer unless listed under inspectionOnly, and unique keys. A step of recommendation-extraction, in place of recommendation-candidates when that step found no normative sentence; the l1-transcription-verbatim Tool satisfies it.

Source: smart-base/L1/skills/smart-l1/transcription-verbatim.md.

How it is deployed and reached

  • Command line. From the repository root: bun run smart-base/L1/scripts/l1-transcription-verbatim.ts --dir <dir of *.l1.yaml> [--root <repo>].
