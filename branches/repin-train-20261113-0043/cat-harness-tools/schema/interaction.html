Description

How a person wants to be asked — the interaction graph's one node kind.

cat-harness/memory/interaction.json is read at the start of every session by scripts/session-start-coord-sweep.sh (jq), which on a parse failure only prints a line — so a malformed node degrades silently. This schema is what catches it.

What is required

A profile list is required and may be empty — an empty list is a person who has said nothing, which differs from a person with no entry (the default block carries that). note and source are optional.

Unknown keys are ALLOWED (a non-strict object), on the rule KgAssetSchema states: a downstream layer may carry a key this layer does not know yet. Anything this layer relies on is named here.
