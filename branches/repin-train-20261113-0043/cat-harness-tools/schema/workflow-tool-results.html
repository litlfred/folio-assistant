Description

Typed results of the workflow engine's tools.

workflow_list, workflow_start, workflow_next, workflow_gate and workflow_complete keep their text and also return the same answer as data (MCP structuredContent). These schemas are that data, published as Tool I/O types so a BPMN gateway or program can read what a step returned instead of parsing text. scripts/tests/workflow-tool-results.test.ts holds each schema equal to the engine's own TypeScript type, so the two cannot drift apart.
