Description

The SKILL-FRAMEWORK vocabulary — actors, capabilities, skills, requirements, the package registry and its Docker and remote-package machinery.

Nothing here is about a folio's content: an actor, a capability probe, a skill's validator list and a package's Docker requirements describe the HARNESS — who is working, on what machine, with which skills installed.

Direction

The harness is the base repository: core may import it, it may not import core. So this module must not depend on types.ts, block-kinds.ts or anything else that describes content. constraints.ts re-exports everything here; new harness code should import this module directly.
