A skill states the capability; this Tool is one way to exercise it. Each skill’s declared input and output contract follows, where it has one.

build-pdf

Builds a paper folio’s PDF locally in the workspace — the monolithic PDF plus split per-chapter PDFs.

The skill declares no I/O contract (schemas/skills/build-pdf/{input,output}.schema.json).

Builds the Lean HTML documentation (doc-gen4) locally in the workspace, for any paper folio’s Lean package.

Source: folio-assistant-sci/skills/content/folio-paper-adapter/build-docs.md.

The skill declares no I/O contract (schemas/skills/build-docs/{input,output}.schema.json).

Processes and tasks

No process step names a skill this Tool satisfies.

How it is deployed and reached

  • MCP. Served as paper_preferences by sage (cat-harness-tools/scripts/sage-mcp.sh), google-drive (cat-harness-tools/scripts/google-drive-mcp.sh), folio-assistant (bun run cat-harness-tools/src/index.ts --stdio --repo .), the servers .mcp.json declares.
  • In process. adapters/paper/tools/preferences.ts — loaded by the harness directly, with no server.
  • GitHub Actions. No workflow in this checkout runs its command.
