Build the review sheet’s Apps Script and a document’s Config tab

Builds Code.gs (--script), the one Google Apps Script every review sheet runs (from review-sheet.gs), and one document’s Config tab rows (--config), filled from the folio’s review/public-comment/sheet-sync.json, its review anchors and the draft’s pdf-line-map.json. The script keeps a public-comment review sheet’s links and joins current: each comment No. links to its comment page; Sections, Page and Line no(s) link to the page of the frozen review draft; Review Change Sets joins its comments, suggested revisions, feedback and dispositions, each No. n linking to its row; and on both tabs Agentic status lists each pull request of the change-set, linked, with its status and what it changed, from the Agent tab. It reads the document’s URLs, tab and column names and data from the sheet’s Config tab (visible, locked to the owner), which the agent writes from these rows. A person pastes the script (one file) into the sheet once (Extensions > Apps Script) and runs installTriggers; from then on the sheet rebuilds itself within about a minute of an edit, with no agent. With "mode": "drafting" in the config it builds the drafting sheet instead: one Contributor Feedback tab where each row is a change set (ids assigned by the script), Sections picked from the document’s table of contents and linked to it, and Issue and Agentic status from the Agent tab.

review-sheet-script

Build, install and reuse the Google Apps Script that keeps a review sheet’s links and joined columns current (Tool review-sheet-sync). Public-comment mode: comment numbers, sections, pages and lines link into the frozen review draft, and Review Change Sets joins its comments. Drafting mode: one Contributor Feedback tab where each row is a change set with its own GitHub issue, and Sections pick from the document’s table of contents. Use when setting up either sheet for a document, when its links are missing or stale, or after a tab, header, anchor or draft link changes.

Source: folio-assistant-core/skills/content/folio-document-adapter/review-sheet-script.md.

The skill declares no I/O contract (schemas/skills/review-sheet-script/{input,output}.schema.json).

How it is deployed and reached

  • Command line. From the repository root: bun run folio-assistant-core/tools/review-sheet-sync/build-review-sheet-script.ts.
  • GitHub Actions. No workflow in this checkout runs its command.

As an API: its operation in the OpenAPI document and the MCP tool list of its layer.

when to choose it
whenA public review is kept in a shared Google Sheet with the public-comment tabs (Review Public Comments, Review Change Sets, Agent - Comments, Agent - Change Sets), and its links or joined columns must stay current without an agent re-pasting them. Also after the review anchors, the draft’s link prefix or a tab or column name changes: rewrite the Config tab (the script stays).
limitsBuilds the script only; installing it is a person’s step in the sheet, since the sheet’s owner must authorise it. It reads only the tabs and headers named in the config. In the reviewers’ columns the link text must be in the cell already: it links what reviewers wrote and does not rewrite their words. The joined columns and Agentic status it writes whole.
costReads three JSON files and writes one file of about 20 kB. In the sheet, a full refresh of 800 rows takes about 20 seconds.
