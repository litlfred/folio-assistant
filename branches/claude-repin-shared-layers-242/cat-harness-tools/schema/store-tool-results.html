Description

Typed results of the tools that read and write the harness's data stores — the work plan, the activity log and the session record.

Each tool keeps its human-readable report and ALSO declares a result output of one of these types, printed when the tool's json flag is set, so a caller, a BPMN gateway or an MCP client can check it. Each schema here is held to its script's interface in both directions by scripts/tests/store-tool-results.test.ts.
