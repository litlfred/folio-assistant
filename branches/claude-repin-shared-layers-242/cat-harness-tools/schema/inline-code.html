Description

Backtick spans in authored prose, rendered as <code>.

Bean titles, glossary definitions and skill descriptions are written in Markdown and reach HTML through generators that escape text verbatim, so without this a reader sees the backticks themselves.

The caller's escaper, not ours

Generators escape differently (the glossary also escapes { for Liquid), so the caller passes its escaper, and it is applied to EVERY piece, the code spans included. The only thing this adds is the <code> wrapper.

What counts as a span

A pair of single backticks on one line with at least one character between them. An unpaired backtick is left as written.
