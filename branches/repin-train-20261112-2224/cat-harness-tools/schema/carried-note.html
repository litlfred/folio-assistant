Description

What an actor carries forward, attached to a node of the knowledge graph.

Todos and memory are one thing

A todo records that a person has something outstanding; a memory entry records what an agent learned. The axes are memory and workflow management, not human and agent:

| | memory | workflow management | |---|---|---| | human actor | todos | — nothing — | | agent actor | MEMORY.md | beans |

Both halves of the memory column answer what do I carry into the next task? and differ only in storage and trigger point. This module is the metadata they share, so a consumer can ask "what is outstanding here" without caring which actor kind left it. Beans are agent workflow management, not a human todo list.

The reference vocabulary has THREE kinds

  • a knowledge-graph node — KgRefSchema: a kind and an id;
  • a person — ExternalIdentitySchema: provider-qualified, because litlfred is not an identity and github:litlfred is;
  • an external artefact — ArtefactRefSchema: an issue, a pull request, a commit — neither a node of this graph nor a person.

The base carries no status

A todo has a lifecycle: open, done, scrapped. A memory entry does not — a TRAP is not "open", and marking one "done" would say the failure it records has stopped being possible. So status lives on the todo, not here.
