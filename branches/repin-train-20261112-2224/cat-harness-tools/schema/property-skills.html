Description

Which skill edits which declaration property: the "edit skills" column of the harness config panel.

This map is TOTAL over the declaration's keys: property-skills.test.ts fails when a key is added to CatHarnessDeclarationSchema without a row here. A row either names the skills that edit the property or records, in words, that none does yet. A recorded gap is shown in the panel as a finding. It is never left blank.

Skills are named by their file stem, which is how reference/skill-instructions/ publishes them. The test checks every name resolves to a skill file.
