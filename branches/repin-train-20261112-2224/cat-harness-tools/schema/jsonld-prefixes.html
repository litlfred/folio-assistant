Description

jsonldPrefixes: the external vocabularies a layer's JSON-LD speaks, as declared data — prefix → namespace IRI.

Each layer declares the namespaces it speaks, and its published context is GENERATED from the prefixes its documents actually use, flattened with the contexts of the layers it needs. So a vocabulary belonging to a higher layer is bound there, and a bound-but-unused prefix cannot exist.

This module is the declaration and the pure merge. It reads no files and runs no generator: the generator and the gate live in the tools layer, and they read every layer's table as data, so no layer has to import the one above.
