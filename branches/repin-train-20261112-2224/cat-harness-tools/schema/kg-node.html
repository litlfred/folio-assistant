Description

The two labels every knowledge-graph node may carry.

A node here is anything the graph names: a declared directory, a role, an actor, a bean-graph node, a skill, a process. title is what a reader sees, description is the sentence under it — one spelling for every node type. Both optional in general; a node type may require either, and kg-audit reports a role with no narrative.

title is not id, and not name

id is the handle other nodes reference. name — where a node still has one — is the layer's own identifier, the thing harness.json calls folio-assistant and publishes artefacts under. title is display text, may contain punctuation an identifier could not, and is translatable. C@T Harness is a title; cat-harness is a name.

The default is no title. displayTitle falls back to name, so a layer whose display text should match its repository omits title rather than repeating name.

Translatable means extractable

KG_NODE_LABEL_FIELDS is the list a translation extractor reads. Nothing else in a KG declaration is offered for translation: an id, a path or a graph typology is structure, and translating structure is how a reference goes dangling — the same rule bpmn-translate.ts follows.
