Description

The ONE implementation of a Tool output's render hint.

schemas/tools/tool.ts declares what a renderer MAY do with an output (RENDER_AS); this does exactly that and no more, so a renderer that puts a tool's output into a page calls this rather than deciding for itself.

Every branch returns an HTML FRAGMENT that is safe to insert:

  • text (and absent) — escaped. No markup, no link, whatever the value holds.
  • url — an <a> only when safeHref accepts the scheme; otherwise the value as escaped text. A refused URL is SHOWN, never silently dropped: a hostile value hidden reads as a missing one.
  • markdown — remark with raw HTML OFF (sanitize: true, GitHub's schema), so <script> and event attributes never survive, and a link whose scheme the sanitiser refuses loses its href.
  • json — escaped inside <pre>. Data is shown, never evaluated.
