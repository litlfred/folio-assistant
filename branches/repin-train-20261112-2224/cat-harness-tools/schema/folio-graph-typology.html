Description

The folio graph typology — registered by core, not declared by the harness.

A folio graph is authored content that the just-the-docs pipeline renders to a website. It is the only renderable kind, and everything that depends on that pipeline belongs to core, so it does not live in schemas/kg/cat-harness.ts. The harness declares the three kinds it can serve — tools, kg, schemas — and core adds this one on top, through the same load-time registration the contribution mechanism uses.

Because it is a registration and not a constant, the harness does not know the kind exists until core registers it, and an unregistered kind is a hard error naming what is known.
