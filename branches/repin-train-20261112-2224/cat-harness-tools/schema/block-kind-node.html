Description

A block kind as a KG node: folio-block-kind/v1, one JSON file per kind in a block-kinds/ graph the OWNING harness declares.

Kinds are discoverable, not centrally managed: no module lists them, and block-kinds.ts DISCOVERS them by scanning every layer's declared block-kinds graph. Each per-kind fact (label prefix, RDF types, builder, profile, whether a label is provable, whether the definition index lists it) is a field here.

Headings are NOT here beyond the English source string: locale headings live in the translation graph.

A LEAF: Zod only, so block-kinds.ts (itself a leaf every schema imports at module load) can parse with it without a cycle.
