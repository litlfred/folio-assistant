Description

A document's footnotes and the marks in its text that call them, as library/<slug>/footnotes.json beside the L1 entry.

Owner, 2026-11-11 (who-iris): "add to L1 doc schema errata" and "also foot notes/marks". Written by the pdf-footnotes.py arm of bun run cat ingest from the page layout (span size, position, the superscript flag). The section text is not changed: a block is still the source's words in the order printed. This file says which foot-of-page text is a note, which mark calls it, and where.

Only a note that a mark in the text calls is a footnote. A small-font line that opens with a number is just as often a table row, a diagram label or a running footer (10665/311941: 159 such lines, none called), so those are kept apart as uncalled_notes, with the marks that found no note as unlinked_marks. Neither is dropped.
