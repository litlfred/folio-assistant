Description

folio-withheld/v1 — what a mounted directory must NOT publish.

The site mount (scripts/mount-instance-docs.ts) copies a layer's directory wholesale, so a publication whose licence refuses redistribution would stay reachable BY URL. The platform cannot know a layer's licence rules; the layer's own generator writes this list from its own data, and the mount honours it for every layer alike.

Each entry names a path relative to the directory the file sits in — a trailing / for a directory, which is withheld with its whole subtree — and the reason, so a reader of the built site can tell "withheld" from "missing".
