Description

User stories — what a reader acting in a role is trying to do.

A story is told AS a role, so it points at the role and the role names no story (data-modelling step 8).

The file is scenarios/stories.json, beside roles.json in the same scenarios graph — the kind the registry names for "Actors, the Roles they take on, and the User Stories those Roles serve".
