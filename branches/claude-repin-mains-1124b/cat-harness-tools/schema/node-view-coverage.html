Description

The node-view coverage report: for each node a declared directory holds, whether it has an IRI, its JSON-LD, a view page and a row on its folder page.

Owner, 2026-11-13 (card A): build the node-view-coverage QA report as proposed in the node-kind view audit, and every listed node kind owes pages (IRI, .jsonld, view page) — no waivers for themes, voices, translation sources, code, QA or software libraries. So those count as missing until they are built, never as waived.

The rule it measures is kg-viewer's §"Every asset has its own IRI": each node owes

1. an IRI — an @id in its layer's export, extensionless; 2. its JSON-LD at <iri>.jsonld (and <iri>.json where its source is JSON); 3. a view page at <base>/<locale>/<harness>/<vis>/<instance>/<id>/; 4. a row on the folder page that links to that page.

A report, not a gate

node-views:report always exits 0, like render:bpmn:check. It is in no index gate list and not always-green. node-views:judge is the author's check: JUDGEMENT_EXIT, 1 only for a finding NEW against the baseline.

Unknown is never zero

A directory not in this checkout (a qa directory kept on qa-reports, say) has declared: "unknown" and a reason. A count that could not be taken (no site to read, a probe over the limit) is "unknown" too.
