Skills it satisfies

A skill states the capability; this Tool is one way to exercise it. Each skill’s declared input and output contract follows, where it has one.

prepare-merge-auto

Full prepare-merge → resolve → merge pipeline. Coordinates with sibling PRs, resolves review comments, asks structured questions only when blocked, then hands the merge to the merge-to-main sub-process, which merges only on the owner’s authorisation.

Source: cat-harness/sdlc/skills/sdlc-core/prepare-merge-auto.md.

Also satisfied by: github-pr-checks, github-pr-comment, github-pr-list, github-pr-request-review, github-pr-view, gitlab-mr-list, gitlab-mr-request-review, gitlab-mr-view.

The skill declares no I/O contract (schemas/skills/prepare-merge-auto/{input,output}.schema.json).

coordinate

Coordinate work across multiple in-flight Claude PRs working toward a shared goal. Post intent + asks on related PRs, identify cherry-pickable work, respond to code-review comments on your own PR, periodically triage sibling PR activity (new comments, CI status, new commits), watch main + newly created branches/PRs, escalate inconsistent findings to the author, and keep a coordination ledger up to date.

Source: cat-harness/sdlc/skills/sdlc-core/coordinate.md.

Also satisfied by: merge-overlap, github-branches, github-pr-comment, github-pr-files, github-pr-list, github-pr-resolve-thread, github-pr-view, gitlab-branches, gitlab-mr-files, gitlab-mr-list, gitlab-mr-resolve-thread, gitlab-mr-view.

The skill declares no I/O contract (schemas/skills/coordinate/{input,output}.schema.json).

How it is deployed and reached

  • Command line. From the repository root: glab mr note create.
  • GitHub Actions. No workflow in this checkout runs its command.

when to choose it
whenThe change proposals live on GitLab — the checkout’s remote is a GitLab project.
limitsGitLab only. For a GitHub repository use github-pr-comment.
costglab, authenticated (glab auth login or GITLAB_TOKEN), and one API round trip per call.
