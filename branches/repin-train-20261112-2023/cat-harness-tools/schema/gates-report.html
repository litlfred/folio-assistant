Description

The typed reports of bun run cat gates and bun run cat check:merged.

Both tools keep their text and their three exit codes. With --report <path> they also write one of these, so a program or BPMN gateway reads which gates failed, which were skipped and why, instead of parsing the text. The exit code stays the verdict; outcome names it, and tells apart the two different exit-1 cases (a gate failed, or every gate passed but one changed the tree).
