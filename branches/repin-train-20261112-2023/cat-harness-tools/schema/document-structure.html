Description

structure.json as a BASE with VARIANTS.

The base holds the fields every format has (a section's id, number, title, level and sizes; the document's title). pdf-structure/v1 is unchanged, as one variant.

A variant adds where a section IS

A PDF section is located by pages; a notebook section by cells. They are not the same unit, so structureOf returns a locator that says which it is. A reader that wants pages asks for kind: "pages" and gets nothing from a notebook.

Read it through the accessor

structureOf is the one way to read a structure.json whose format is not known in advance; a reader that parses the file itself misreads the next variant. A new format (HTML, DOCX) is a new variant here and no reader changes.
