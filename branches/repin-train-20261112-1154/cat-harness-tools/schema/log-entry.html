Description

The agent activity log — what an agent did, when, and in which process.

An agent adds an entry whenever it starts or ends a task or has a log message. Entries live under fsh-guts/logs/. fsh-guts is a kind kept out of every published graph, so a log cannot leak into the folio's linked data however verbose it gets.

Persistence is OFF by default, and that is not the same as "no log"

The default is write locally, ignored by git: the agent can read back what it wrote this session, and nothing reaches the data store until a workflow or the config asks for it.

The state must be reported, never assumed, so the agent never believes it has an audit trail it lacks: LogCapture is a three-valued answer rather than a boolean.

Each file carries $schema, so a log entry is identified by what it declares, not by its directory.
