Description

The durable record of a detangle measurement — what is pinned, and what is not.

kg-detangle writes its measurement to a committed sidecar, so a regression in the authority map, the boundary arithmetic or the cohesion computation shows as a diff against the last recorded value.

What is pinned

Size, cohesion, the authority and direction counts — not the verdict.

| field | pinned | why | |---|---|---| | size | yes | a derived fact about the node set | | internal, inbound, outbound | yes | see below — a ratio never travels alone | | cohesion | yes | a derived fact | | enforcedBoundary, recordedBoundary, proseMentions | yes | the authority counts | | wrongDirection, undeterminedDirection | yes | the DIRECTION counts — see below | | role | no | derived from the counts above; pinning it duplicates them | | verdict, clauses | no | a threshold comparison that flips on unrelated edits |

verdict is excluded because a group near a threshold flips on a change that moved nothing about it, and a sidecar that churns stops being read.

The direction counts are pinned because they are not thresholds: wrongDirection counts edges whose directionOf said wrong-direction, which changes only when an edge or a declaration changes — the event worth failing on. undeterminedDirection (an edge whose layer declares no needs) rides with it, so an edge moving from wrong-direction to undetermined does not read as a fix.

The raw counts ride with cohesion, per detangle.ts's rule for oneWayness: "Reported with the raw counts, never instead of them." cohesion is internal / (internal + inbound + outbound), so pinning the ratio alone would let three edges becoming thirty pass unrecorded.
