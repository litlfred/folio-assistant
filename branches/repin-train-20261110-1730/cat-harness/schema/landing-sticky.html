Description

The landing page, as a board of sticky notes.

Initiation creates an empty folio (if none exists) and attaches a sticky per initiator, carrying the initiated harness's description and the four onboarding links.

The set is COMPOSED, not enumerated here

This module holds the node type and one projection: stickyFromContribution turns a layer's declared StickyContribution into a sticky. The layers declare; this builds. Where each sticky comes from, and why it is a declaration rather than a code registry, is in schemas/content/sticky-contribution.ts.

A note, not a todo

A landing description is not a task: no status, nothing to complete. So it extends CarriedNoteSchema directly — the general "note somebody carries, attached to the graph" that TodoNodeSchema also extends — and stays out of the todos graph.

The anchor is NARROWED, not merely set

CarriedNote.anchor is optional across three states. Here it is PageAnchorSchema and required: a landing sticky is page-global, with no block to sit on, so one carrying a block anchor does not parse.
