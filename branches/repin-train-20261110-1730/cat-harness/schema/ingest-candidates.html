Description

library/<slug>/candidates.json — Stage B's proposals for an entry, written by scripts/extract-candidates.py (a class extractor, the --aspects-only aspects, or by hand in the same shape) and turned into one typed block each by pipeline/gen-library-jsonld.ts.

Proposals only: nothing here is folio content. The whole-document fields (document_class, validated, disposition) are optional: an aspect run or a hand-written record says nothing about the whole document.

Each candidate is open beyond the fields every reader relies on: an extractor carries what its class knows (grade_nearby, label_prefix).
