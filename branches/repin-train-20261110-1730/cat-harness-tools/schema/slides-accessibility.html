Description

accessibility.json: a slide deck's accessibility report, written by scripts/slides-structure.py beside its structure.json.

Per check, never an overall score: one number would weigh a missing slide title against a missing alt text, and nothing supports that weighting. The three checks the package cannot answer carry state: "undetermined" with a reason, so a report cannot read as clean over what nobody measured.
