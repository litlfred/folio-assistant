Description

A coding convention — context attached to a PROCESS, not loaded everywhere.

A SKILL is what you need in order to perform a task; a CONVENTION is how the output must look while you are inside a particular process (e.g. software development under CRDM). An agent implementing under CRDM has them; an agent adjudicating a translation does not. Conventions resolve like roles in the subprocess stack — the union along the call path.

Absent binding means none

The resolver returns [] for an unbound step, never "all": a convention that fires everywhere is unconditional prose again.
