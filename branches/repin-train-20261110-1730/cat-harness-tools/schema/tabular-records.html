Description

What makes a dataset findable.

A CSV or spreadsheet in uploads/ is stored but not findable: a grep for a column header finds nothing. tabular.jsonld records sheet names, headers and shape, so the header vocabulary joins the L1 source graph.

The narrative is a state machine, and starts empty

narrative (what the data is about) is a module:schemas/narrative record, which starts not-authored with no text, moves to draft when an agent writes one, and reaches confirmed only when a HUMAN accepts it.

A null shape is not an empty sheet

rows/columns are nullable and shape_source says which case it is. A sheet whose <dimension> is absent or unparseable has an UNKNOWN shape; 0 × 0 would say it is empty.

Only fixed-width is still written as v1

Delimited text and workbooks are read as CSVW (folio-tabular-csvw/v1) by core's extractors through the tabular-csvw slot. This schema still accepts csv, xlsx and ods so already-committed records keep validating; the one format still written as v1 is fixed-width.
