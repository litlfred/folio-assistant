Description

dak-task-annotations/v1 — the reviewable record of a DAK's BPMN task annotations, one file beside each .bpmn (<file>.tasks.json).

A DAK document follows every workflow figure with "<letter>. <PROCESS> BUSINESS PROCESS NOTES AND ANNOTATIONS": a numbered item per step of the figure, with » bullets describing it. Those items are the DAK's task table. They reached the L1 library only as flattened prose, and no BPMN task carried one (findings/bpmn-task-annotations-2026-11-18.md).

This file is the hand-off between the extractor that reads them (../scripts/dak-task-annotations.ts) and the knowledge graph that represents them (./extract-bpmn.ts emits dak-task describes bpmn-task). A person can read it, correct a match, and commit; the KG is rebuilt from it.

Deliberately independent of FHIR and of BPMN extensions (owner, 2026-11-18: "I want task annotation represented in KG. I am not keen on adding extensions to bpmn"; "I don't want something so FHIR dependent"): references are the DAK's own ids — persona labels as the lane names them, data element, requirement and decision table ids as the DAK spreadsheets declare them — never FHIR canonicals, and the BPMN file is read, never written.
