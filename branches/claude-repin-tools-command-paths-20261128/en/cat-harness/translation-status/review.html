translations — review

Every catalogue in every locale, and whether a person has reviewed it. Tick the machine translations you find acceptable, or open mistranslation… on a cell to suggest better text for its strings, then press Submit. That opens a GitHub issue prefilled with your review. Filing it makes you, by your GitHub login, the reviewer, and a workflow turns it into a pull request recording your verdict. Owners, members and collaborators of a layer's repository can adjudicate it. Submitting needs JavaScript; the table reads without it.

A suggestion is applied as a #, fuzzy string and flags the catalogue for review: nobody else has reviewed your text yet. Accepting sets the catalogue reviewed, pinned to the version you saw, and it shows as stale once that catalogue changes. Coverage numbers are on the status page.
