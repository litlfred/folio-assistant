Description

The swimlane glossary's retirement ledger: its tag and its shape.

Harness state: glossary-export writes it and it is hosted in cat-harness (glossaryHomeFor). A role's own names are authored on the role (otherNames, formerNames). The old tag folio-glossary-ledger/v1 is still accepted on read, so a dependent instance's committed ledger is not refused.
