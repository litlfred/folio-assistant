Description

Workshops: the didactic layer over a set of journeys.

What a workshop is

A workshop teaches from journeys (user-scenario.ts). It is kept apart from them because one journey can be taught by several workshops, to several audiences, and a journey must not change when a workshop does. So a workshop POINTS AT step ids and no scenario names a workshop.

A workshop holds:

| field | what | |---|---| | modules | the sessions, in order: a title, the one question the module carries, learning objectives, the printable sheet it fills, the resources it uses | | tables | the reference tables a room fills or reads (decision rights, legal bases, substitution patterns, cost drivers): generic rows, so each workshop names its own | | steps | per journey step: questions for the room (each tagged with its module), a facilitator cue, the capabilities the step needs, and which rows of which tables the step touches | | assessment | the scales a capability is rated on at a table (exists / partial / absent; blocks us now / within 12 months / can wait), and the standing line read with them | | discussion | closing questions, each in a module and tied to the steps it is about | | sheets | the printable canvases (A3 or A4), each filled in one or more modules | | resources | job aids, handouts, readings, slides and links, each tied to modules or steps | | presentation | how the journeys viewer presents the workshop in a room: the app frame's words, the story in one sentence, whose record the trust ladder follows, the presenter's note, the outward links | | lab | the Discussion view as a table's working steps (team, use case, readiness, who decides, components, mapping, pathway, summary), each with a timer and a DISCUSS prompt, after DPI-H Lab; what a table writes is kept in its browser and assembled into one summary |

A question is a question: a module asks a room to NAME, not to decide.

The workshop's steps name a scenario and a step id. A scenario id is looked up first in the workshop's own layer and then in every layer the checkout mounts, so a workshop may teach from journeys another layer holds.
