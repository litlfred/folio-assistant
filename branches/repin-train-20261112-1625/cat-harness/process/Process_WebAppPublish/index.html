namePublish a web app — declared, translated, built at its own route
summaryHow any layer publishes an interactive app it holds as source, without becoming a harness.
descriptionHow any layer publishes an interactive app it holds as source, without becoming a harness. The layer declares a `web-app` directory; the app's UI strings go through the harness's own translation process; the harness's `apps` visualiser (Tool `web-app-build`) checks, builds and publishes it at `<locale>/<harness>/apps/<id>/`, with no site chrome, loaded only when a reader opens it (skill `web-apps`).
