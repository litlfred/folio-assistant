Description

WHEN A SWEEP STEP WAS LAST RUN — so skipping it leaves a trace.

The session-start sweep asks the agent to run check:session-staleness (a session stopped holding a question for the owner is otherwise invisible). The sweep cannot run it itself: the input is a list_sessions listing only an agent holds. So the check writes a last-checked mark to the state branch, and the next sweep can tell "nobody checked" from "checked, nothing waiting".

One file per check, overwritten

A mark answers one question — when did this check last read its input — so it is a single file per check (<check>.json), replaced on each determined run.

Only a DETERMINED run writes one

A run that could not read its input did not check anything; a mark for it would make "could not determine" look like "checked".
