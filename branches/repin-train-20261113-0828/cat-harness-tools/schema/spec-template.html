Description

Spec template schema and validator for platform feature specifications (spec-kit).

A feature specification in spec-kit follows upstream's spec-template.md. Upstream marks three sections as mandatory: - User Scenarios & Testing - Requirements - Success Criteria

And two sections as recommended: - Edge Cases - Assumptions

Plus a metadata header carrying Feature Branch, Created, and Status.

This module defines the machine-readable contract for the spec template, validates that specs conform to it, and refuses adjudicated status for a spec that still carries unresolved clarification markers.
