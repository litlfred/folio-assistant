Description

The context an agent provides when asking "which decision methodology fits?"

Complements MethodologyFrontMatterSchema — that schema declares what a methodology IS; this one declares what a decision NEEDS. The selector skill matches a DecisionContext against each methodology's applies-when and the method-family criteria tables.

You pick a method with this schema, then use it to produce a decision request (decision-request.ts).

Every dimension is optional: an agent provides what it knows, and the problem is often half-formed. A context with only questionType still routes via methodology-adoption's four-question protocol; more dimensions narrow the ranking.
