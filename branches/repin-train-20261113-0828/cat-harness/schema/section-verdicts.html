Description

Section verdicts — which ingested sections are not PROSE.

The analogue, for a section, of image-verdicts.json for an image: one inspection's judgement, recorded as DATA beside the documents it judges (a library root's section-verdicts.json), so it can be reviewed line by line and read by every consumer rather than re-decided by each.

A style guide prints sample pages — Lorem-ipsum covers, font specimens, table samples. They are the source's own content but not prose: a summary, translation or index of them describes filler.

Roles

  • specimen — the page exhibits a typographic or layout sample; its words are placeholder or sample text, not the document speaking.

The enum is closed: each new role arrives with the consumer that honours it.

Who reads it

  • scripts/summaries.ts — a specimen block has status specimen: neither prose nor backlog, so the drain does not summarise filler, and the block stays VISIBLE as a specimen rather than disappearing from the counts.
  • scripts/lsi.ts unitsOf — a specimen section is not an index unit.
