The ideal informalized output should meet the following criteria:
1. Semantically Equivalent to the Lean 4 Theorem and Proof: (informalization success =
T)
2. Intuitive Terms without Lean 4 Functions: Both problem statement and proof use intuitive
terms without Lean 4 functions mentioned, proves the intended theorem successfully, and
can be independently understood without prior knowledge of Lean 4. (informal proof
correctness = T)
Check the instruction and demo examples in the fewshot prompt for reference of an ideal informaliza-
tion case. You can use tools like https://jsoneditoronline.org/ to compare two model
output files more easily.
