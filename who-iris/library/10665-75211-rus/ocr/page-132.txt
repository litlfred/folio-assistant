Цель

Процесс разработки плана действий по внедрению электронного здравоохранения начинается
с понимания и логического распределения по группам мероприятий, необходимых для
реализации национальной концепции электронного здравоохранения и рекомендаций,
которые были разработаны в рамках Части 1. Распределение мероприятий по группам позволит
определить общие направления деятельности, которые, в свою очередь, лягут в основу плана
действий по внедрению электронного здравоохранения.

Действия
> Определить основные направления деятельности.
> Определить промежуточные результаты для направлений деятельности.

> Определить мероприятия, необходимые для достижения промежуточных результатов в
рамках каждого из направлений деятельности.

> Определить дополнительные мероприятия, связанные с изменением и внедрением.
> Определить взаимосвязи между мероприятиями.
> Разработать индивидуальный план действий по каждому из направлений деятельности.

> Определить риски, связанные с реализацией планов действий в рамках каждого из
направлений деятельности.

> Уточнить направления деятельности в рамках внедрения электронного здравоохранения
(факультативно).

Промежуточные результаты

Примерный план в рамках каждого из направлений деятельности, отображающий
промежуточные результаты, необходимые мероприятия, факторы взаимосвязи, временные
рамки, а также риски.
