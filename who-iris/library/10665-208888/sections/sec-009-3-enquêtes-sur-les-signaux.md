Enquêtes sur les signaux 
Pour évaluer si un vaccin donné peut causer une MAPI donnée, il faut prendre en compte toutes les 
données sur les cas individuels de MAPI ainsi que les données de surveillance et, s’il y a lieu, les 
enquêtes en grappes et les données non cliniques.
