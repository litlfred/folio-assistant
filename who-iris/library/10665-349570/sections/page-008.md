The cutoff for data included in this Infographic Snapshot is 15/04/2021. The
year provided for each endnote is the date of the latest available data with
an earliest date of 2011. Where data is not available in an international
data source ‘No data’ is stated. This does not mean that no data exists for
this indicator but that no data was found in internationally validated data
sources.
