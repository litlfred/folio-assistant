D1
Sistemas de análisis
«Sistemas que examinan y procesan los resultados de la información producida por el middleware».(8) 
Son herramientas de datos que se utilizan para facilitar la toma de decisiones. (1) 
Otros descriptores:
•	 Analítica predictiva 
•	 Análisis de datos prescriptivos 
•	 Análisis de datos de diagnóstico 
•	 Análisis de datos descriptivos 
Las áreas funcionales incluyen:
•	 Visualización de datos  
•	 Paneles Inteligencia empresarial  
•	 Paneles de datos clínicos 
D2
Intercambio e interoperabilidad de datos
Proporciona capacidades informáticas para respaldar la gestión del intercambio de datos y la 
interoperabilidad entre aplicaciones y servicios en toda la iniciativa de salud digital. (1) 
Otros descriptores:
•	 Capa de interoperabilidad 
•	 Intercambio de información sobre salud 
Las áreas funcionales incluyen:
•	 Autenticación 
•	 Servicio de emparejamiento de entidades 
D3
Bases de datos
«Un sistema empresarial utilizado para el análisis y presentación de informes de datos estructurados y 
semiestructurados de múltiples fuentes».(10) 
Otros descriptores:
•	 Repositorios  
•	 Almacenamiento de datos 
•	 Repositorio nacional de datos
Las áreas funcionales incluyen:
•	 Procesamiento de datos (extracción, 
transformación, carga - ETL)  
•	 Consolidación de datos  
•	 Depuración de datos  
•	 Presentación de informes 
D4
Sistemas de vigilancia ambiental
«Los sistemas de información de la gestión ambiental son sistemas técnico-organizativos para obtener, 
procesar y poner a disposición sistemáticamente información ambiental pertinente».(11) 
Otros descriptores:

ambiental
