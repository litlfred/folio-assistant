4.1
Gestión de datos 
Enfoques digitales para la gestión de datos, incluidos la recopilación, la agregación/
organización y el almacenamiento de datos para su análisis. Esto puede incluir intervenciones 
independientes centradas exclusivamente en la recopilación y agregación de datos, así como 
servicios de datos para apoyar otras intervenciones, como la visualización de datos.
