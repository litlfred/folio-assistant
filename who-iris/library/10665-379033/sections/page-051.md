4.2
Codificación de datos 
Enfoques digitales para codificar datos y gestionar el uso de conjuntos de datos normalizados.
4.2.1 
Análisis de 
datos no 
estructurados 
en datos 
estructurados
- 	 Gestión de datos incompletos 
- 	 Depuración automatizada de datos 
Ejemplo sin publicar: Esta herramienta 
elaborará un conjunto de algoritmos 
automatizados para depurar y vincular 
información no estructurada (por ej., 
historiales médicos) a conjuntos de datos 
estructurados.
4.2.2 
Fusión, 
eliminación de 
duplicaciones 
y organización 
de conjuntos 
de datos o 
terminologías 
codificados
-	 Mantenimiento y creación de versiones 
de normas terminológicas de 
informática en materia de salud 
-	 Servicios terminológicos 
-	 Interoperabilidad semántica 
Ejemplo sin publicar: Aplicaciones de 
gestión terminológica para normalizar datos 
e identificar definiciones similares en todos 
los sistemas.
4.2.3 
Clasificación 
de códigos 
de morbilidad 
o causas de 
mortalidad
-	 Registro de causas de muerte 
-	 Codificación de la CIE, codificación 
clínica para informes y seguros 
-	 Mapeo de terminología, códigos y 
formatos locales 
Programa informático de terminología 
diagnóstica: «Consiste en una enciclopedia 
de términos médicos que tiene un tipo de 
codificador de formato de libro de códigos 
automatizado e incorpora todos los códigos 
de la CIE-10 y todos los códigos de la CIAP-
2. Está concebido para utilizar sin conexión y 
es muy adecuado para historiales médicos 
impresos. Permite que el codificador escriba 
el diagnóstico/problema de salud en una 
barra de búsqueda y revise las selecciones 
de códigos, las tablas de búsqueda y otras 
anotaciones automatizadas que facilitan la 
elección del código más preciso».(68)
