Tout d'abord, vous devrez comprendre comment le programme de santé fonctionne actuellement, ou le flux de 
travail du programme. Il faut pour cela réfléchir aux tâches à accomplir pour atteindre les objectifs et les priorités 
du programme de santé formulés dans le Chapitre 2. En d'autres termes, vous analyserez les différents processus 
du programme de santé et identifierez les blocages qui empêchent une prestation optimale de ces services, 
pour aboutir à un diagramme de l'état actuel. 
Le processus de cartographie de l'état actuel comporte trois étapes.
1.	
Déterminer les processus du programme de santé à cibler.
2.	
Cartographier le parcours de l'utilisateur (illustré par un flux de travail) dans chacun de ces processus.
3.	
Identifier les blocages dans chaque flux de travail.

Comment un système d'information 
peut-il nous assister dans notre

	+ Définir les tâches spécifiques

	+ Estimer si l'environnement est

	+ Déterminer si les systèmes

numérique existants peuvent
