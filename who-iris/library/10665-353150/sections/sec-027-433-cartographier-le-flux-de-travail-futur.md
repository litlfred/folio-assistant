CARTOGRAPHIER LE FLUX DE TRAVAIL FUTUR 
Une fois que vous avez recueilli les différentes exigences 
et évalué leurs implications sur les utilisateurs finaux 
et les parties prenantes, vous pouvez commencer à 
conceptualiser le flux de travail de l'état futur. Dans 
le Chapitre 3, vous avez schématisé l'état actuel 
du programme de santé. Vous pouvez maintenant 
développer de nouvelles versions de ces diagrammes, des 
diagrammes de flux de travail de l'état futur, pour illustrer 
les processus dans le système souhaité où l'intervention 
de santé numérique surmonte les blocages (voir Schéma 
4.3.3.1). Pour ce faire, réimaginez le programme de santé 
optimisé avec une mise en œuvre de la santé numérique 
en place. Indiquez les moments de santé numérique, 
ces points du processus où les interventions de santé 
numérique s'attaquent aux blocages pour améliorer 
l'état actuel. Le nombre de diagrammes de l'état futur 
peut différer du nombre de diagrammes de l'état actuel, 
car vous devrez peut-être prévoir des emplacements 
supplémentaires où les données seront gérées ou utilisées 
pour la prise de décision. 
Pour créer les diagrammes de flux de travail de l'état futur, 
suivez ces étapes.
1.	
Examinez les diagrammes de flux de travail de 
l'état actuel et les profils des utilisateurs finaux. 
La prise en compte de ces facteurs permettra de 
s'assurer que l'intervention est réaliste.
2.	
Redessinez les diagrammes de flux de travail 
du Chapitre 3 pour inclure les changements 
numériques et non numériques proposés qui, 
ensemble, permettent de relever les défis du 
système de santé.
