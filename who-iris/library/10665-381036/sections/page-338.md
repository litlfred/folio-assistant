3.3.2 Data extraction and management 
Using a pre‐developed data extraction form, two review authors worked independently to extract 
data on the following characteristics. See Appendix 3: Data extraction form.  
• General study characteristics (e.g. publication year, study design, setting) 
• Participant characteristics (e.g. age, gender, median CD4 cell count)  
• Target condition (e.g. pulmonary tuberculosis, extrapulmonary tuberculosis, or 
both) 
• Index tests (e.g. type of LC-aNAAT and LF-LAM, specimen types, positivity threshold)  
• Reference standard (e.g. reference standard type, types of tests) 
• Study results (two-by-two table data (true positives [TP], false negatives [FN], false 
positives [FP], and true negatives [TN]). We recorded the number of participants, in 
whom diagnostic testing was attempted [attempt for sputum and urine collection, 
transportation to lab, performance of index tests] but who did not have a result for 
any reason along the diagnostic testing pathway. 
For studies where we could not extract these data directly from the publications, we reached out to 
study authors for data. Data were reported back in the format of three-by-three-by-two tables 
designed for the purpose of our review. See Appendix 4: Data reporting form for primary study 
authors. Some study authors shared individual-participant data (IPD).  
Two review authors independently extracted data from each study. We resolved disagreements 
through discussion and, if necessary, by involving a third review author as arbiter. We contacted 
study authors for missing data and clarifications. We extracted data using Microsoft Excel and 
entered data into Review Manager Web directly [The Cochrane Collaboration.].  
3.3.3 Assessment of methodological quality 
We assessed the methodological quality of included studies using QUADAS-2 [Whiting 2011] and 
QUADAS-C [Yang 2021a] tools. See Appendix 5: QUADAS-2 and Appendix 6: QUADAS-C. QUADAS-2 is 
a tool for assessing risk of bias in and applicability of single test accuracy estimates; QUADAS-C is an 
extension to QUADAS-2 for assessing risk of bias in comparative accuracy estimates. Review authors 
independently assessed each study. We resolved disagreements through discussion and, if 
necessary, by involving a third review author as arbiter.   
3.3.4 Statistical analysis and data synthesis 
See Appendix 7: Data analysis plan. From each study, we estimated sensitivity, specificity, and their 
absolute differences (parallel testing minus component test) between index tests under comparison 
(together with 95% confidence intervals) and visualised these in forest plots and summary receiver 
operating characteristic (SROC) plots.  
If at least 3 studies were available for a given analysis, we performed bivariate random-effects meta-
analysis [Reitsma 2005; Chu and Cole 2006] using a Bayesian approach to estimate summary 
sensitivity, summary specificity, the 95% credible interval (CrI) and the 95% prediction interval (PI) of 
each test.
