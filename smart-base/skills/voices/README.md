# voices

Editorial voice profiles derived from this layer's own `library/` -- `who-digital-health` is the first. Every rule cites `{ libraryId, sectionId, pages, quote }` resolving into `library/`, and `check:voices` refuses one whose citation does not resolve, which is what makes a voice auditable rather than asserted. The id is `voices`, the CONVENTIONAL one, so this overrides the default rather than joining it. Declared in the commit that created its content. Issue #877, bean `7mi0`.

Part of [SMART Base](../../README.md) 0.1.0, declared as `voices`, holding `voices`.
