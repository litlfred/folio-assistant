4. Determine the requirements
4.1 Identify user personas
Identify key user personas and related user 
personas. A user persona is a generic depiction of 
a relevant stakeholder or end user who would be 
interacting with the reporting system. Personas 
help identify the wants, needs and constraints 
of the end users. User personas can be based 
on real individuals or a fictional character that 
represents a combination of real individuals and 
stories. The closer the personas are to reality, the 
more likely the system will meet real needs. See 
Annex 2 for a user persona template.
The reporting system is primarily utilized by 
skilled health care professionals working within all 
levels of health care settings. Skilled health care 
professionals include:
•	
Doctor/medical practitioner
•	
Nurse
•	
Pharmacy technician
•	
Pharmacist
•	
Dentist
•	
Public health worker
See Tables 7 and 8 for examples of user personas.
4.2 Define user scenarios
Define clear user scenarios for each identified 
persona (see Table 9). These scenarios help 
translate roles into specific, practical use cases, 
ensuring that solutions are tailored to local 
workflows, digital readiness and user capacities. 
A good user scenario should describe the context, 
the user’s objective, the challenges they face 
and how the tool addresses them. This approach 
supports more intuitive design, targeted training 
and successful adoption – leading to better data 
quality and programme outcomes.
