This reference architecture is a shared resource rather than a fixed blueprint, and different 
470 
actors use it in different ways. 
471 
 
472 
• 
Governments and policymakers can use it as a planning and investment framework — to 
473 
prioritise among the seven health goals, sequence investment along the phased path, and 
474 
hold programmes and partners to a common architectural standard. 
475 
• 
Architects can use it as a reference model to adopt, adapt, or map a national architecture 
476 
(as described in section 4.4), and as the source of the component definitions and design 
477 
principles a national design should respect. 
478 
• 
Implementers and suppliers can use it as a specification source — the data models, actor 
479 
definitions, exchange profiles, and conformance criteria against which conformant systems 
480 
are built and existing systems assessed. 
481 
• 
Development partners can use it to align their contributions with national shared 
482 
infrastructure rather than building parallel systems, expressing support in terms of the 
483 
components and capabilities the country has prioritised. 
484 
• 
Reviewers and assessors can use it as a benchmark for coverage and conformance, and 
485 
as the canonical decomposition of goals into capabilities and components that makes 
486 
comparison across contexts possible. 
487 
 
488 
Using the architecture well is less about adopting every element verbatim than about adopting 
489 
its discipline: a common vocabulary of components and capabilities, a shared set of open 
490 
standards, and an explicit, testable relationship between national choices and the reference 
491 
model.
