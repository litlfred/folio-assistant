Profiles and specifications are useful only if compliance with them can be verified. Countries 
399 
should establish minimum conformance requirements for each DPI-H component and define the 
400 
testing mechanisms through which conformance is assessed. An interoperability test bed39 — 
401 
an openly available, standards-based testing environment offering validators, simulators, and 
402 
test-management tooling — supports FHIR conformance testing and can be adapted to country-
403 
specific implementation profiles, giving countries a shared means of verification rather than one 
404 
rebuilt from scratch for each procurement. Countries should consider requiring conformance 
405 
certification against published profiles as a condition of approval for procurement of DPI-H 
406 
components, so that every system entering the national digital health ecosystem contributes to 
407 
interoperability rather than undermining it.
