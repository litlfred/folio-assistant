A reference architecture describes what a system needs to do and how it should behave — but 
250 
for countries to translate architectural intent into implemented systems, they need a more 
251 
concrete layer of specification: profiles that define the data structures, roles, transaction 
252 
patterns, and integration interfaces that give the architecture its practical form. This section 
253 
addresses that need, providing guidance on the minimum level of specification that countries 
254 
should establish regardless of the technology choices they make in implementation.
