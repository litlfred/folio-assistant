# glossary

The WHO glossary: folio-glossary/v1 schemes of terms the WHO publications use under more than one name. Owner, 2026-09-30 (bean ftu0): who-style-guide owns it rather than who-iris, because the glossary is a HOUSE rule about wording, like the voices, while who-iris holds the publications themselves. An alternative label is recorded only where a publication STATES the equivalence, and each term cites that sentence in who-iris across the instance boundary; a count or a latent-semantic cosine is never the evidence. The scheme's own source is a who-style-guide voice, so its terms are minted in this instance's namespace. Rendered on the glossary/ page and checked by check:glossary, both of which read every instance's declared glossary directory.

Part of [who-style-guide](../README.md) 0.1.0, declared as `glossary`, holding `glossary`.
