# findings/

Authored findings about smart-trust's own pages, kept for the owner rather than built at publish.

- `wireframes/` — the as-is wireframes of the visualisers `smart-trust.json` declares, one directory per wireframe (`intent.md`, the candidate `.html`, `authors.json`, and `checks/` written by `bun run cat wireframe:check`). `index.json` says which visualiser each covers; `bun run cat check:wireframes` reads it.
