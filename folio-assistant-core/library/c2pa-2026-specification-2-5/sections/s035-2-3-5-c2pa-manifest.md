#### 2.3.5. C2PA Manifest

The set of information about the _provenance_ of an [asset](#_asset) based on the combination of one or more [assertions](#_assertion) (including [content bindings](#_binding_to_content)), a single [claim](#_claim), and a [claim signature](#claim-signature-definition). A [C2PA Manifest](#_c2pa_manifest) is part of a [C2PA Manifest Store](#_c2pa_manifest_store).

> **NOTE:**
> A [C2PA Manifest](#_c2pa_manifest) can reference other [C2PA Manifests](#_c2pa_manifest).
