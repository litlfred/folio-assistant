## Appendix H: Deprecated Constructs

This annex provides historical information about constructs that have been deprecated in this specification. Claim generators shall not use these constructs. Validators should still accept them for backwards compatibility as described in [Appendix E, _Considerations for Deprecation_](#versioning_annex).
