## Appendix G: CDDL Schemas

This annex is the definitive, consolidated source for all [CDDL Definition](https://www.rfc-editor.org/rfc/rfc8610) schemas used in this specification. It includes every version of every schema — current and historical. All schemas in this annex are normative.

> **NOTE:**
> Each section of the specification shows the current data structures inline for reading convenience. This annex is authoritative and contains everything, including deprecated structures and prior schema versions.
