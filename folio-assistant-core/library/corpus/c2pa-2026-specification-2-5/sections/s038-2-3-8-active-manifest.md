#### 2.3.8. Active Manifest

The last manifest in the list of [C2PA Manifests](#_c2pa_manifest) inside of a [C2PA Manifest Store](#_c2pa_manifest_store) which is the one with the set of [content bindings](#_content_binding) that are able to be validated. For the full structural description, see [Manifest Store](#_manifest_store).
