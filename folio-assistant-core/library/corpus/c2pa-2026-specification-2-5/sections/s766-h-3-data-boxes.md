### H.3. Data Boxes

> **IMPORTANT:**
> This section is retained for historical purposes. The concept of a data box has been deprecated in favour of a standard assertion that uses a standard JUMBF Embedded File content type box to contain the data. For more information, see [Section 16.6.6, “Embedded Data”](#_embedded_data).
