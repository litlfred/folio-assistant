# bibliography/ page: as-is intent

**Covers:** the `bibliography` visualiser `folio-assistant-core` declares in `folio-assistant-core.json` (`renderedBy: bibliography-page`, `coversKinds: [references, catalogue]`, `subgraphs: directory`), routed at `en/folio-assistant-core/bibliography/`. It is generated by `folio-assistant-core/scripts/bibliography-page.ts` (`bun run cat bibliography:page`, the `bibliography-page` Tool) and gated by `check:bibliography`.

**Candidate:** `as-is.html`, the index page, with the page of one sub-graph drawn below it. Checked at web 1280 and mobile 390.

**Who it is for:** a reader or an author of a folio who wants a reference the knowledge graph holds, whether a folio cites it (a `references` node) or a catalogue holds it (a Dublin Core record). It works like the glossary viewer, limited by path to sub-graphs and single assets.

**What they need to do:** find a reference, read its citation, see where it came from and whether the library holds it, and export the whole list, one sub-graph's list, or one reference, in the format their tool reads.

**What it must show**, as the generator writes it:

On the index (`<route>/`):
- what the page holds: `references` directories' `folio-reference/v1` nodes and `catalogue` directories' Dublin Core records, as one list;
- the export of every reference shown: BibTeX, CSL-JSON, RIS and Dublin Core / BIBO JSON-LD, as files beside the page;
- a "By sub-graph" line linking each declared directory's page, with its count;
- a filter box with a live count;
- per reference, in an ordered list: the citation (up to three authors then "et al.", year, title, container, volume, issue, pages, publisher); its key as a link to its own anchor; its provenance (`catalogue` or `authored`); its DOI or URL; its ISBN; the source file it was read from; where the library holds it; and its own export as BibTeX, RIS and CSL-JSON downloads.

On each sub-graph's page (`<route>/<sub-graph>/`): the directory, its instance and kind, a link back to all references, the same four exports over that directory alone, and the filter and list.
