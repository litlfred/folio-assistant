Four lanes, one per kind of actor:

| lane | who | owns |
|---|---|---|
| Author / guideline developer | person | the PICO, the appraisal, the grade |
| Evidence agent | system | retrieval across the three classes |
| Trusted registries and observatories | **external** | whether a citation resolves |
| Work plan — beans | shared | every gap and every unverified citation |

The registries lane is external because **authority is not something the folio
can assert about itself**: it is resolved at the publisher.
