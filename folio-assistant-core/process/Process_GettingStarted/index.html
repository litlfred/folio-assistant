summarySomebody said "create a folio": work out which request they meant, with the branch computed by a decision table that may answer "ask", and what has to be true before anything is written.
descriptionSomebody said "create a folio": work out which request they meant, with the branch computed by a decision table that may answer "ask", and what has to be true before anything is written. folio-assistant — getting started: from "create a folio" to a live site. "Create a folio" is five different requests. Gateway_Intent computes which one from decisions/folio-intent.dmn rather than letting the agent assume, and `ask` is one of the outcomes the table can return. Gateway_Live applies the same construction to publication, with `unknown` kept distinct from `not-yet`. Source of truth: this file. The SVG under docs/assets/img/workflows/ is generated from it by `bun run cat render:bpmn` — never hand-edit the SVG.
