# cat-openapi-scripts

The rendering sub-pipeline: `ingest-openapi.ts` copies a configured document in verbatim with its provenance; `gen-openapi-pages.ts` writes a JSON-LD node and a thin page per document and per operation; `templates/` holds the one shared loader that draws them in the browser.

Part of [C@T OpenAPI](../README.md) 0.1.0, declared as `cat-openapi-scripts`, holding `code`.
