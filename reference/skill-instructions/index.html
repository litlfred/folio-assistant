Skill instructions

The prose instruction bodies the LLM loads (via skill_fetch) when it runs a skill. These are generated from the skill source markdowns, so the published reference always matches what the agent actually reads.

For each skill’s typed input/output contract, see the Skill schema reference; for the conceptual overview of skills, roles, and how they compose with the LLM, see Skills & roles.

Lifecycle skills

Skill Id Schema Summary
Content Authoring content-author schema Create and develop content artifacts according to the project plan.
Content Feedback Collection content-feedback schema Gather and triage feedback on published content for future iterations.
Content Planning content-plan schema Plan content development by defining scope, team, timeline, and sprint cadence.
Content Publication content-publish schema Package, version, and publish approved content.
Content Retirement content-retire — Deprecate and retire content that is no longer current or needed.
Content Review content-review schema Formal review and approval of validated content before publication.
Content Testing content-test schema End-to-end testing of content artifacts in realistic scenarios.
Content Validation content-validate schema Validate authored content against schemas, standards, and clinical accuracy.
