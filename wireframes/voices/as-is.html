The description states BOTH what the skill does and when to use it

as-description-states-function-and-trigger

A description that names only the function cannot be routed to. State the operations and the triggering situations, in the concrete terms a real request would contain.

structurecritical
State both what the skill does and when it should be used, and include the concrete terms a relevant task would contain.arxiv-2607.25032v1#sec-004-writing-the-description, p4-5
