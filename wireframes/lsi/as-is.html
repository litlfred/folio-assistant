Latent semantic indexes

A latent semantic index places every unit of a prose graph — a library section, a skill, a bean — in a space built from which words occur together, so units that discuss the same thing in different words sit close. Every neighbour and finding is a proposal, never a relation the graph asserts.

Method: Latent Semantic Indexing (node lsi), with correspondence analysis as its parallel track; skill lsi-indexing.
