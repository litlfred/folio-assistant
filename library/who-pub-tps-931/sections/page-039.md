WHO Editorial Style Manval

Lists

Inaneffort to rationalize the presentation of lists, the following are the
styles that should generally be adopted. Where circumstances make
any of these inappropriate, clarity and common sense should prevail in
selecting an alternative.

Format I

1. Where subsequent reference makes it essential that items ina list be
numbered, and always for recommendations within a Technical
Report, numbers should be set full out to the left and followed by a
full point.

2. Items of this sort will often contain more than one sentence. They
should start with a capital letter and end with a full point.

3. Where more than one line of text is involved, second and subse-
quent lines should be blocked to the first tab stop.

Format 2

1. All the rules set out in Format 1 apply in this Format, which deals
with items requiring a further subdivision.

2. When an individual item in a list is to be broken down beyond the
numbering level, subitems should be identified and set out as
follows:

(a) by the use of lower-case letters, in parentheses, set at the first tab
stop;

(b) for long lists, all letters may be used, ie. including i, | and 0;
(c) where a subitem runs to more than one line of text, second and
subsequent lines should be blocked to the second tab stop;

(d) in general, the nature of these subitems is likely to be such that
each can be terminated with a semicolon (except the last,
which requires a full point).

Format 3

¢ Where certain parts of a text are to be itemized, for example for
emphasis, but there is no requirement for numbering, the use of
“bullets” is recommended.

© Bullets should be set full out’ to the left, and should be of a size
appropriate to the appearance of the text.
