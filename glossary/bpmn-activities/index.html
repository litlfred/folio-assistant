Glossary: BPMN activities

Candidate terms extracted from every BPMN task and call activity: name as the label, its own <documentation> as the definition, the element id as the code. Each is the asset’s own text, verbatim and not curated, and carries the badge “candidate, extracted”. A person promotes one by authoring it. Authored terms, the counts and the sources are on the glossary index.

<name>/<name>.json with name, version, repository (the planned home), livesAt (where it sits today), needs, and only the directories that exist, each declared with its files in one commit (bean dh4f). <name>/platform.ts from the first commit, so no climb out of the directory ever needs rerouting.
